## B 类问题根因分析
本章的核心问题是代码示例严重虚构。经联网搜索验证 AOSP 实际 API 后确认：
- Android 15 的 ProfilingManager 使用 4 个 RequestBuilder 子类（非 ProfilingConfig.Builder）
- 结果通过 Consumer<ProfilingResult> 回调返回（非 ProfilingStatus 轮询）
- Android 16 系统触发使用 addProfilingTriggers()（非 registerProfilingListener()）
- Android 17 新增触发器与文中列出的不同

这表明原始草稿在加工时未充分对照 AOSP 源码，依赖了模型的"猜测"而非实际 API 文档。
