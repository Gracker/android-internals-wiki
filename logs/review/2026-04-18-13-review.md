## ⚠️ 严重发现：AI 编造内容

经 web search 验证，Android 17 EyeDropper API 确实存在，但章节中描述的 API 实现**与真实 API 完全不符**。真实 API 为简单的 Intent-based workflow，章节中描述的整个类体系（EyeDropper/EyeDropperConfig/CrossDeviceColorPicker 等）均为 AI 编造。

**真实 API：**
- `Intent("android.intent.action.OPEN_EYE_DROPPER")` 启动系统取色器
- `registerForActivityResult` 接收结果
- `intent.getIntExtra("android.intent.extra.COLOR", default)` 获取颜色
- 无需 MediaProjection 或 Accessibility 权限
