## 内容取舍原则

1. 优先保留规范路径、较新的深度审校状态与更完整的一手来源边界。
2. 标题相近但讨论层级不同的正文不合并，例如基础机制与应用实践、系统 API 与工具使用、工具介绍与 APM 集成。
3. 只有高相似度、同一主题且互为旧稿/错位副本的文件才删除或合并。
4. 对有独有有效内容的重复项先合入规范正文，再删除旧路径；不把低置信度提纲、错误 API 或无来源量化结论带入正文。
