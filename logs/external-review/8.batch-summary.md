## 3. 发现的重大风险 (P0/P1)
- **[P0] 04-other-scenarios.md**：将 ViewPager2 的 `offscreenPageLimit` 错误地说成可以设为 `0`，这在代码中会直接导致抛出 `IllegalArgumentException` 崩溃。必须修正！
- **[P1] 01-responsiveness-principles.md**：错误地声称 Input 事件到达 App 进程后会被“投递到主线程的消息队列中”。实际上它是通过 native socket fd 唤醒 Looper 并直接执行回调的，并未封装成普通的 Java Message 进行排队。
- **[P1] 02-app-launch.md**：错误地声称 `ViewRootImpl` 是在 `onResume` 中创建的。实际上它是在 `onResume` 完全返回之后的 `ActivityThread.handleResumeActivity` 中通过 `WindowManager.addView` 触发创建的。
- **[P1] 03-launch-optimization.md**：严重误导了国内 Baseline Profile 的生效机制，认为没有 Play 商店就只能靠 `adb`，完全忽略了 `androidx.profileinstaller` 在应用启动时自动写入 Profile 供后台 `bg-dexopt-job` 编译的能力。
- **[P1] 09-game-performance.md**：将 Generational Concurrent Copying GC 错误地归属到了 Android 17，实际上这在 Android 10 中就已引入。
