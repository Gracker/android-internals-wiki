- **[P1][原理链完整性][Java Heap Sampling vs Snapshot]**
  - **原文位置**：§13.2 "Java Heap Sampling" 部分
  - **原文问题**：未明确区分 `android.heapprofd` (持续采样) 与 `android.java_hprof` (单次快照) 的应用场景。
  - **源码/一手资料锚点**：`external/perfetto/protos/perfetto/config/profiling/java_hprof_config.proto`
  - **运行原理说明**：`heapprofd` 的 Java 支持是基于 ART 内部的采样机制，适合观察内存增长趋势；而 `android.java_hprof` 类似传统的 HPROF，是 STW (Stop-The-World) 的完整快照。
  - **为什么这是重要缺失**：读者可能会在需要快照分析时误用采样配置，导致无法拿到完整的对象存留关系。
  - **建议补充方向**：简要说明两者的选择逻辑：看“谁在分配”用 `heapprofd`，看“谁在持有没有释放”用 `java_hprof`。
