## 五、P1 问题（重要缺失）
- **[P1][源码准确性][HWC 的核心职责]**
  - **原文问题**: 只列举了 `DEVICE`、`CLIENT`、`SIDEBAND` 三种合成类型，漏掉了极重要的 `SOLID_COLOR`。
  - **源码 / 一手资料锚点**: AOSP `hardware/interfaces/graphics/composer/2.1/types.hal` 及 `frameworks/native/services/surfaceflinger/DisplayHardware/HWC2.h` 中的 `HWC2::Composition` 枚举。
  - **缺失内容**: 遗漏了 `SOLID_COLOR`（纯色图层）和 `CURSOR` 类型。
  - **运行原理说明**: HWC 支持直接绘制纯色（如视频播放时的黑色遮罩/DimLayer），无需由 App 申请 BufferQueue 或由 GPU 渲染。这是节省 GPU 带宽的极常见手段。
  - **为什么这是重要缺失**: `SOLID_COLOR` 在 Android 界面系统中极其常用，如果遗漏，读者会误以为所有蒙层都会引起 GPU 回退或消耗 Buffer。
  - **建议补充方向**: 补充对 `SOLID_COLOR` 和 `CURSOR` 的简要说明，特别是它在视频背景黑边或 UI 遮罩中的应用。

- **[P1][原理链完整性][SurfaceFlinger 的合成决策流程]**
  - **原文问题**: 在讲 Mixed composition（混合合成）时，没有解释 UI（CLIENT）悬浮在视频（DEVICE）上方的“挖孔”（Hole Punching）机制。
  - **关键代码逻辑**: SurfaceFlinger 的 `CompositionEngine` 和 RenderEngine 的 `CLEAR_REGION` 逻辑。
  - **缺失内容**: 未解释 Client Target 是如何不遮挡底层视频的。
  - **运行原理说明**: 当视频层（DEVICE）在下，UI 层（CLIENT）在上时，SF 用 GPU 渲染 UI 到 Client Target 缓冲区。由于视频区域不需要 GPU 处理，SF 会在这个 Client Target 中将对应视频的区域保持“完全透明”（即所谓“挖孔”）。随后 HWC 把底部的 DEVICE 层和顶部的 Client Target 进行叠加。
  - **为什么这是重要缺失**: 读者在实战中经常遇到“弹出一个 UI，视频为什么不卡/没有回退”，如果不理解 Client Target 的透明挖孔原理，就无法建立对 Mixed Composition 的正确空间想象。
  - **建议补充方向**: 在第 5 步 `setClientTarget()` 周围，增加关于 Client Target 透明区域和 Hole Punching 的补充解释。

- **[P1][版本差异/实战落地][在 Perfetto 和 dumpsys 中识别 Overlay]**
  - **原文问题**: 提供的命令 `dumpsys SurfaceFlinger | grep -A5 "SurfaceView"` 且 Perfetto 识别标准为“GPU Track 没有额外合成任务”。
  - **源码 / 一手资料锚点**: Android 12+ 的 `dumpsys SurfaceFlinger` 层级树与 `Composition` 状态表格；Perfetto 中 `RenderEngine::drawLayers` slice。
  - **缺失内容**: 较新版本系统 dump 格式变更及 Perfetto 正确判定方法。
  - **运行原理说明**: 
    1. 新版 Android `dumpsys SurfaceFlinger` 会在结尾打印统一的 `HWC layers` 列表，用 grep -A5 很容易漏掉核心字段（当前通常显示为 `Device` 和 `Client` 而非全大写）。
    2. 在 Perfetto 中，UI 动画会导致 GPU 持续工作，不能用“GPU Track 没有任务”来反推视频 Overlay 成功。正确的做法是：查看 Perfetto 的 RenderEngine track 下的 `drawLayers` 块，在其 Args 参数中查看被提交给 GPU 的 Layer 列表。如果视频 Surface 不在这个列表里，且能在 DPU/MDSS track 看到独立图层，说明它走了 Overlay。
  - **建议补充方向**: 修正这两个实战排查手段，提供更准确的 Android 12+ dumpsys 查看位置和 Perfetto `drawLayers` 参数检查法。
