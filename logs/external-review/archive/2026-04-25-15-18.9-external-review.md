## 三、 详细问题单

### 3.1 SurfaceView (ch18.06)
- **[P0][版本差异]** 遗漏 Android 14 对 Alpha 的重磅支持。Android 14 解决了 `SurfaceView` 无法半透明的痛点，支持任意 Alpha 混合。如果是 `ZOrderOnTop`，Alpha 作用于内容；否则作用于“挖洞”区域。
- **[P2][原理改进]** 建议补充 `BufferStateLayer` 的角色，解释 BLAST 事务如何让宿主 Window 的透明矩形与独立 Surface 同步。

### 3.2 TextureView (ch18.07)
- **[P0][源码准确性]** `onFrameAvailable` 回调线程。`TextureView.java` 在内部监听中未指定 Handler，默认回调到 UI 线程，这才是导致其受主线程卡顿影响的物理原因。

### 3.3 Vulkan (ch18.09)
- **[P1][版本差异]** 缺失 Android 15 (VRA15) 强制要求 Vulkan 1.3 的关键信息。VRA15 标准化了特性集，对性能选型至关重要。

### 3.4 SurfaceControl (ch18.10)
- **[P1][版本差异]** 缺失 API 36 (Android 16) 新增的 `ASurfaceTransaction_setBufferWithRelease`。这是图形 Buffer 生命周期管理的最佳实践。

## 四、 可复用知识资产
- **Android 14 SurfaceView Alpha**: `setAlpha()` 现在在 SurfaceView 上有效，不再是二元的。
- **Android 16 Buffer Release**: `setBufferWithRelease` 提供 per-buffer 的 release callback，彻底解决 buffer 回收的时序问题。
- **ANGLE 路径**: Android 15 强化了通过 ANGLE 将 GLES 翻译为 Vulkan 的路径。

## 五、 回炉问题单总结
1. **修正 SurfaceView 章节**：补充 Android 14+ Alpha 支持细节。
2. **修正 TextureView 章节**：精确化回调线程模型描述。
3. **补充 Vulkan 章节**：加入 Android 15 (VRA15) 要求。
4. **补充 SurfaceControl 章节**：前瞻性引入 API 36 的 Release Callback 接口。
