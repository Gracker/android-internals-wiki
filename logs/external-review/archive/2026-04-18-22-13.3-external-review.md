## 四、P0 问题（事实错误）
- [P0][交叉引用一致性/事实错误][颜色编码：线程状态色]
- **原文问题**：“Runnable（浅绿色）... 浅绿色表示线程已经准备好执行” 以及快速判断口诀里的“浅绿色长：调度瓶颈”。
- **源码 / 一手资料锚点**：Perfetto UI 源码及历史 SysTrace 定义。
- **核验结论**：在 Perfetto 与 SysTrace 中，`Runnable` 状态的标准颜色始终是**蓝色 / 浅蓝色 (Blue / Light Blue)**，而非浅绿色。绿色家族专门用于表示 CPU 正在执行的 `Running` 状态。
- **为什么错**：性能优化高度依赖视觉直觉。告诉读者去找“浅绿色”会导致他们在一堆蓝色的 Runnable 块前迷失，甚至错误地将 Running 当作 Runnable。
- **建议修正方向**：将“浅绿色”全部修正为“蓝色 / 浅蓝色”，修改判断口诀里的对应词汇。
