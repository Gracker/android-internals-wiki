## 五、P1 问题（重要缺失）
- **[P1][版本差异][14.12] ApplicationExitInfo 兼容性**
  - **原文位置**：`ApplicationExitInfo：先把稳定性事实说准`
  - **原文问题**：暗示其为基础通用能力，未提及 API 30+ 限制。
  - **源码锚点**：`frameworks/base/core/java/android/app/ApplicationExitInfo.java` (Added in API 30)
  - **建议修正方向**：明确该 API 在低版本不可用，并提示旧版本（API 26-29）需依赖传统的崩溃/ANR 捕获。

- **[P1][源码准确性][14.12] JankStats UI 状态关联**
  - **原文问题**：对 `JankStats` 描述过于简略，未提及 `PerformanceMetricsState`。
  - **核验结论**：`JankStats` 的核心竞争力在于它解决了原始 `FrameMetrics` 无法感知“当前是谁在滑动”的问题。
  - **建议修正方向**：在 JankStats 小节补充其对 UI 状态追踪的支持。

- **[P1][知识盲区][14.12] 插桩 vs 采样成本**
  - **原文问题**：将 `Matrix` 和 `btrace` 并列为增强层，未说明技术路线差异。
  - **原理说明**：Matrix 基于 ASM 编译期全量插桩，开销中等且增加包体积；BTrace 3.0 采用同步采样，开销极低。
  - **建议补充方向**：在“运行时开销”考量中增加插桩与采样的对比。
