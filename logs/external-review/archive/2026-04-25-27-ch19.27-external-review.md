### 9.4 可复用知识资产（高价值新增知识）
- **一手资料：** `/proc/self/task/[tid]/stat` 的第 14 (utime) 和 15 (stime) 字段是统计线程 CPU 消耗的核心依据。
- **关键源码路径：** `bionic/libc/include/sys/mman.h` (mmap 系统调用定义)。
- **代码逻辑摘要（无锁环形缓冲区）：**
  ```cpp
  // 必须使用 memory_order_release 确保数据写入先于 tail 指针更新
  tail.store(next_tail, std::memory_order_release);
  // 必须使用 memory_order_acquire 确保读取到最新的 data
  if (next_tail == head.load(std::memory_order_acquire)) { ... }
  ```
- **Mmap 头部设计范式：**
  - `Header (64 bytes)`: Magic(4b) + Version(4b) + HeadOffset(4b) + TailOffset(4b) + Checksum(8b) + Payload...
  - 每次写入后，先更新 Payload，最后原子更新 TailOffset。
- **Trace 观察点：** 在 Perfetto 中观察 `mm_filemap_fault` 事件，可以监测 APM 写入时是否触发了过多的硬缺页中断。
