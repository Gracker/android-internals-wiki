### Android 15 16KB page size 兼容性调研 (2026-05-02)

基于源码调研发现 Android 15+ 的 16KB 页面大小适配关键点：

#### 1. NDK 27 max-page-size 问题
- **问题**：mprotect(1, PROT_READ|PROT_WRITE) 在 16KB 设备上返回 `Invalid argument`
- **原因**：NDK 27 的 libc.a 未同步 AOSP 修复（[android-review.googlesource.com/c/platform/bionic/+/2713655](https://android-review.googlesource.com/c/platform/bionic/+/2713655)）
- **解决方案**：在 build.gradle 中添加链接器标志：

```gradle
android {
    defaultConfig {
        ndk {
            abiFilters 'arm64-v8a'
        }
    }
    externalNativeBuild {
        cmake {
            arguments '-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON'
        }
    }
}
```

#### 2. 内存对齐验证工具
- **工具**：LEAFECODES/Check-16kb-page-size-for-filetypes
- **验证点**：
  - PT_LOAD 段对齐（p_align ≥ 16384）
  - 虚拟地址对齐（p_vaddr % p_align == 0）
  - 文件偏移对齐（p_offset % p_align == 0）
  - 同余性要求（p_vaddr % p_align == p_offset % p_align）

#### 3. React Native 集成方案
- **CMAKE 链接器标志**：
```gradle
project.ext.react = [
    "-DCMAKE_SHARED_LINKER_FLAGS=-Wl,-z,max-page-size=16384",
    "-DCMAKE_MODULE_LINKER_FLAGS=-Wl,-z,max-page-size=16384",
    "-DCMAKE_EXE_LINKER_FLAGS=-Wl,-z,max-page-size=16384"
]
```

#### 4. MTE 内存标记扩展
- **要求**：使用 `PROT_MTE` 标志进行内存标记扩展
- **适用场景**：安全敏感型应用，需要内存错误检测
- **示例**：
```c
mmap(addr, len, PROT_READ | PROT_WRITE | PROT_MTE, 
      MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);
```
