## 证据锚点
- Android 16KB page size 官方获取方式：`getconf PAGE_SIZE`、`Os.sysconf(OsConstants._SC_PAGE_SIZE)`、`/proc/<pid>/smaps` KernelPageSize、`AT_PAGESZ`。
- android15-6.6 `fs/f2fs/segment.h`：`__get_secs_required(..., bool *curseg_p)`；`has_not_enough_free_secs()` 使用 `bool curseg_space` 与 `free_secs > upper_secs` / `free_secs <= lower_secs` / `!curseg_space`。
- android15-6.6 `fs/erofs/decompressor.c`：LZ4 + 可选 LZMA/DEFLATE，无 ZSTD；upstream Linux v6.10 `fs/erofs/Kconfig` 已有 `CONFIG_EROFS_FS_ZIP_ZSTD`。
- Cronet public API：`org.chromium.net.RequestFinishedInfo`；Android 34 `android.net.http.RequestFinishedInfo` 带 `{@hide}` / prototype 注释，Android 35 SDK source 已无该类。
