- 复核结论：Perfetto UI macros / Extension Server 的团队共享口径与当前官方文档一致：宏是 Settings > Macros 中的命令序列，Extension Server 分发 macros、SQL modules、proto descriptors。
- 复核结论：Perfetto SDK 的 TrackEvent / Custom Data Source 分层、`DataSourceDescriptor` 注册、TraceConfig 中 `data_sources.config.name` 启用口径与官方 SDK 文档一致；正文已说明 Custom Data Source 需要 Trace Processor 侧导入支持。
- 复核结论：`android.os.Trace.beginSection/endSection`、`ATrace_beginSection/endSection`、NDK async tracing API 的 API level 边界正确：Java sync API 自 API 18 起，Java async / counter 自 API 29 起；NDK sync API 自 API 23 起，NDK async / counter 自 API 29 起。
