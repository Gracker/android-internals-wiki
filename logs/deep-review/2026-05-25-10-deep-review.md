## 复核依据
- Android 17 behavior changes: `Safer Native DCL—C` 要求 `System.load()` 加载的 native 文件只读，否则抛 `UnsatisfiedLinkError`。
- Android 14 behavior changes: `Safer dynamic code loading` 建议动态加载文件打开后、写入内容前标记只读，避免 race；既有文件可先校验完整性再 relabel。
- Dynamic Code Loading security risks: DCL 应避免使用，必须使用时应使用可信位置并在加载前做完整性校验。
- Android NDK JNI tips: 常规 native 库加载入口仍是 `System.loadLibrary()`，旧系统 ReLinker 属于历史兼容路径。
