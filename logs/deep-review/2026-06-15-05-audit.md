## 核对资料
- Android Developers Microbenchmark 文档（Last updated 2026-05-19）：`androidx.benchmark` plugin 默认 full AOT 需 Benchmark 1.3.0-beta01+ 与 AGP 8.4.0+；可用 `androidx.benchmark.forceaotcompilation=false` 关闭。
- Android Developers Macrobenchmark 文档：Macrobenchmark 适合启动、滚动、复杂 UI 交互；测试模块为独立 `com.android.test` module；target app 需 `profileable`，且 ProfileInstaller 1.3+ 用于 profile capture/reset 与 shader cache clearing。
- AndroidX API reference：`BaselineProfileRule` 标注 `@RequiresApi(28)`，完整支持 API 33+ 或 rooted API 28+；`CompilationMode` 在 API 23 only Full；`CompilationMode.Partial` 为 API 24+，`BaselineProfileMode.Require` 需要 ProfileInstaller 与 AGP 7.0+ 打包 baseline profile；`BlackHole.consume()` 用于防止 DCE。
