## 复核证据
- AOSP `android-17.0.0_r1`：`external/perfetto/docs/instrumentation/tracing-sdk.md` 可访问；文档明确 Perfetto Tracing SDK 是 C++17 userspace tracing library，支持 `kInProcessBackend` / `kSystemBackend`，SDK 由 `sdk/perfetto.h` 与 `sdk/perfetto.cc` 两个 amalgamated 文件组成。
- Perfetto 官方 in-app tracing 文档：in-process 示例使用 `kInProcessBackend`、`track_event` data source 与 `TracingSession::ReadTraceBlocking()`；system-wide 示例使用 `kSystemBackend` 将应用事件送入系统 Perfetto service。
- Perfetto API/ABI 文档：`include/perfetto/public` C API/ABI 仍标注 not stable yet，正文生产接入需锁定 SDK revision 的边界成立。
- Android Developers `ProfilingManager`：类与 `requestProfiling(...)` 为 API 35；`addProfilingTriggers(...)` 等触发式接口为 API 36。
- Android Developers `ProfilingTrigger`：类为 API 36，部分 trigger 常量在 API 37 增补；正文“`ProfilingTrigger` 从 API 36 开始提供触发式 profiling 能力”未越过 Android 17/API 37 边界。
