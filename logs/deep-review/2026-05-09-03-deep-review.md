## 证据锚点
- AOSP mainline `bionic/linker/linker.cpp::do_dlopen()`：`find_containing_library(caller_addr)` 决定 caller namespace。
- AOSP mainline `bionic/linker/linker_soinfo.cpp::to_handle()/generate_handle()`：targetSdk >=24 返回 opaque handle，不是库内地址。
- ShadowHook upstream `shadowhook/src/main/cpp/sh_island.c`：`sh_island_alloc()` 先匿名页，后 ELF gap。
- ShadowHook upstream `arch/arm64/sh_inst.c` / `arch/arm64/sh_a64.c`：no-island 备份 20/24B；`br_ip` helper 为 16B，入口 patch 常带 NOP 或走 `br_rx`。
- ShadowHook upstream `arch/arm/sh_inst.c` / `arch/arm/sh_t32.c`：Thumb with-island 4B 相对跳；no-island `sh_t32_absolute_jump()` 为 8/10B。
- ShadowHook upstream `sh_linker.c`：constructor 保存 Android 4.x dlfcn 地址，注释为降低被 PLT-hook 概率。
- AOSP mainline `linker.cpp::soinfo::protect_relro()` 与 `linker_phdr.cpp::phdr_table_protect_gnu_relro_16kib_compat()`：compat mode 仍执行 RELRO 保护。
- LLVM compiler-rt `clear_cache.c`：AArch64 `__clear_cache` 读 `CTR_EL0`，使用 `dc cvau` / `dsb ish` / `ic ivau` / `dsb ish` / `isb sy`。
