### 维度 1：源码/官方 API 引用准确性

1. [P1] `src/part2-performance/ch18-rendering-pipelines/16-game-engine.md:214` — ADPF API 版本说明不准确。
   - 问题：正文把 `updateTargetWorkDuration` 写成 Android 13 才增加；官方 Java API 文档显示它自 API 31 可用。正文还写 “Android 14+ CPU load up/down hint”，当前公开 `PerformanceHintManager` / NDK performance hint 文档没有这个 API 命名。
   - 建议：重写为 API 31 Java、API 33 NDK、API 34 `setThreads`、API 35 `setPreferPowerEfficiency` / NDK work-duration 扩展的版本矩阵；无法确认的 “CPU load up/down” 删除或标 `[待验证]`。

2. [P1] `src/part2-performance/ch18-rendering-pipelines/16-game-engine.md:222-226` — Frame Rate API 的 Java 签名与 Android 11+ 边界不匹配。
   - 问题：`Surface.setFrameRate(float, int, int)` 是 API 31；Android 11/API 30 只有 `Surface.setFrameRate(float, int)`。
   - 建议：拆分 API 30 与 API 31 的调用形态；native 侧同步区分 `ANativeWindow_setFrameRate` 与带 change strategy 的入口。
