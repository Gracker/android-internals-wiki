## 证据锚点
- Android CLI 官方文档（2026-05-19）：`android describe` 输出项目结构/产物 JSON；`android run` 不构建、需 `--apks`；`android layout --diff` 返回上次内部快照后的变化；`android screen resolve --screenshot --string` 替换 `#<number>` 为坐标；`studio` 命令要求 Android Studio Quail 2 Canary 1+ 且 Gemini in Android Studio 已登录。
- Journeys 官方文档（2026-05-19）：Journey 是自然语言指令集合，由 agent 转成 App 交互；官方页未给固定 `android journey ...` 子命令。
- AOSP SurfaceFlinger：android-11.0.0_r48 / android-12.0.0_r34 有 `onMessageReceived`、`onMessageInvalidate`、`onMessageRefresh`、`postComposition`，无 `doComposition`、`handleMessageRefresh`、`commit()`、`composite()`；android-13+ 有 `commit()`/`composite()`；android-16.0.0_r1 使用 `SFTRACE_NAME` 与 WorkloadTracer `Commit`/`Composition`/`Post Composition`。
- 16 KB page size 官方文档：Android 15 起 AOSP 支持 16 KB page size 构建；Android 15 时该选项默认未开启；Android 16 新增 `PRODUCT_CHECK_PREBUILT_MAX_PAGE_SIZE := true`；Google Play 兼容性页要求 2025-11-01 起 targeting Android 15+ 的新应用/更新支持 16 KB page size。
