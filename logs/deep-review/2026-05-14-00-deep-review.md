## 资料复核
- AndroidX `core-splashscreen` release notes：`core-splashscreen:1.2.0` 已于 2025-11-05 release；`1.2.0-alpha02` 是 2024-09-04 alpha。
- AndroidX `SplashScreen.kt`：API 31+ 调平台方法；API 31 以下复制平台行为，已知例外是 launch screen 上 Animated Vector Drawable；`installSplashScreen()` 要在 `super.onCreate()` 之前调用；兼容实现存在 `Impl#setOnExitAnimationListener()`。
- AOSP android-15.0.0_r1 starting-surface 路径存在：`frameworks/base/libs/WindowManager/Shell/src/com/android/wm/shell/startingsurface/`。
- Android Developers：`Context#MODE_MULTI_PROCESS` API 23 废弃；`SharedPreferences` 不支持跨进程使用。
- Android Developers：`ApplicationStartInfo` added in API level 35，获取入口为 `ActivityManager.getHistoricalProcessStartReasons()` / `addApplicationStartInfoCompletionListener()`，包含启动原因、启动类型、startup timestamps。
- Android launch-time docs：Vitals 慢启动阈值为 cold 5s / warm 2s / hot 1.5s，使用 TTID；`reportFullyDrawn()` 过早调用会让 TTID/TTFD 报同一 TTID 值。
