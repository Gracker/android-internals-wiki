## 一手资料与锚点
- AOSP `android-16.0.0_r1` `SQLiteGlobal.java`：`getDefaultPageSize()` 从 `/data` block size 初始化并支持 `debug.sqlite.pagesize`；`getWALSyncMode()` / `getWALAutoCheckpoint()` 读取 `db_wal_sync_mode` / `db_wal_autocheckpoint`。
- AOSP `android-16.0.0_r1` `config.xml`：`db_wal_sync_mode=NORMAL`，`db_wal_autocheckpoint=100`，注释标明单位为 database pages。
- AOSP `android-16.0.0_r1` `SQLiteConnectionPool.java`：WAL 模式下 `mMaxConnectionPoolSize = SQLiteGlobal.getWALConnectionPoolSize()`，非 WAL 当前为 1。
- AOSP `android-16.0.0_r1` `SQLiteDatabase.java`：`ENABLE_WRITE_AHEAD_LOGGING`、`enableWriteAheadLogging()` 路径存在。
- Android Developers SQLite performance 文档：建议启用 WAL；WAL 下 synchronous mode 设为 `NORMAL`；`ATTACH DATABASE` 是例外条件。
- source.android Compatibility WAL 文档：Android 9 引入 Compatibility WAL；Room `AUTOMATIC` 在 API 16+ 且非 low-memory 设备默认启用 full WAL。
- SQLite 官方 WAL/PRAGMA 文档：WAL 支持读写并发但有 checkpoint；page_size 是数据库页大小，可用 `PRAGMA page_size` 查询/设置。
