[P0][源码/API 签名错误] L203-L205：滑动帧率 Macrobenchmark 示例中的 `list?.drag(Point(...), Point(...))` — 正文示例把 `UiObject2.drag()` 写成两个 `Point` 参数（起点、终点）。AndroidX UIAutomator 当前源码只提供 `drag(Point dest)` 和 `drag(Point dest, int speed)`，内部起点固定取 `getVisibleCenter()`；不存在 `drag(Point start, Point end)` 这个重载。因此该示例不能编译，读者复制到 Macrobenchmark 工程会直接遇到 API 签名错误。
     - 建议：改成合法 UIAutomator 调用：若只需要模拟列表滚动，优先使用 `list?.swipe(Direction.UP, 0.8f)`；若保留 drag，则写成 `list?.drag(Point(list.visibleBounds.centerX(), list.visibleBounds.top + 100))`（可按需加 speed 参数），并说明手势起点由 `UiObject2` 的 visible center / gesture margin 决定。
     - 证据：AndroidX `UiObject2.java` 仅有 `drag(Point dest)` / `drag(Point dest, int speed)`；源码内部调用 `mGestureFactory.drag(center, dest, speed)`，起点由 `getVisibleCenter()` 决定。
