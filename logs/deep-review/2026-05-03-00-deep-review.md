#### 具体问题
1. [P0] [版本差异] L255-L297 Vulkan Timeline Semaphores — 正文称“Android 16 强制要求新设备支持 Timeline Semaphores”以及“基于 Android 16 VPA16 设备要求”。复核 Khronos VP_ANDROID_16_minimums.json，VPA16 追加的是 VK_EXT_host_image_copy、maintenance6 等扩展/特性，未出现 timelineSemaphore 或 VK_KHR_timeline_semaphore；Android Developers 公开口径也只是 Android 10 新 64-bit 设备要求 Vulkan 1.1、VPA 每年定义 profile。该断言会把 Vulkan 1.2/timeline feature 与 Android 16 CDD/VPA 要求混同。
   - 建议：删除“Android 16 强制要求新设备支持 Timeline Semaphores”口径，改成“Timeline Semaphore 是 Vulkan 1.2 核心特性之一，实际可用性需查询 VkPhysicalDeviceTimelineSemaphoreFeatures.timelineSemaphore；Android 16/VPA16 不应作为强制依据”。
1. [P1] [原理断裂] L273-L295 Vulkan Semaphore 与 Android Native Fence 的 Interop — AOSP android-16.0.0_r1 的 VulkanManager::createReleaseFence()/finishFrame() 只创建带 VkExportSemaphoreCreateInfo(VK_EXTERNAL_SEMAPHORE_HANDLE_TYPE_SYNC_FD_BIT) 的 VkSemaphore，未设置 VkSemaphoreTypeCreateInfo，也没有 VK_SEMAPHORE_TYPE_TIMELINE。该路径是 binary external semaphore → sync fd/native fence 的桥，不是 Timeline Semaphore 的直接导出路径。Khronos 也明确 WSI API 仍不支持 timeline semaphore。
   - 建议：把“HWUI native fence export/import”独立成 Binary/External Semaphore 桥接小节；Timeline Semaphore 只描述 Vulkan 队列内部同步，并补充 WSI/native fence 边界不能直接用 timeline 替代。
1. [P2] [数据缺失] L299-L307 16KB 页对 Fence 路径的潜在影响 — 该段虽标注待验证，但仍把 16KB 页、TLB miss、GPU IRQ → dma_fence signal → SurfaceFlinger wakeup 延迟串成较具体因果链；目前缺同机 4KB/16KB kernel ftrace、perf counter 与 Perfetto fence wait 尾部抖动数据。
   - 建议：在补齐 GPU IRQ 时间戳、dma_fence_signal、sched_wakeup、TLB miss/perf counter 对照前，建议保留在“待验证研究假设”附录，不放入版本演进主线。
1. [P3] Perfetto fence 可观测性建议补充具体 ftrace 事件名（dma_fence:*）与 UI 中 slice/track 名称，避免把 android.fence 写成稳定 data source 名。

[P0] [源码错误/命令错误] L113-L187 自定义 Perfetto Metric 示例 — 官方 trace-based metrics 要求 SQL 文件名与 TraceMetrics extension 字段一致，并提供 {metric_name}_output view，view 中用 proto builder 函数（如 ColdStartMetric(...)）和 RepeatedField(...) 组装输出 proto。当前示例只 SELECT metric_name、SUM(duration_ns)，没有 cold_start_metric_output，也没有填充 repeated phases，无法按 --run-metrics 生成 TraceMetrics.cold_start_metric。
   - 建议：补成两段：先 CREATE VIEW cold_start_phases AS ...；再 CREATE VIEW cold_start_metric_output AS SELECT ColdStartMetric('phases', (SELECT RepeatedField(ColdStartPhase(...)) FROM cold_start_phases), 'total_duration_ns', ...)。同时说明 SQL 文件名必须是 cold_start_metric.sql。
1.
