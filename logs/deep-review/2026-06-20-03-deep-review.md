## 核验材料
- AOSP android-17.0.0_r1：`frameworks/base/core/res/res/xml/power_profile.xml` 默认 profile 仍使用故意不准确的占位值，display / cluster 现代命名存在。
- AOSP android-16.0.0_r1：`CpuPowerCalculator.java` 包含 `getAveragePowerForCpuScalingPolicy()`、`getAveragePowerForCpuScalingStep()`、`getCpuEnergyConsumptionUC()`；`ScreenPowerCalculator.java` 包含 `MIN_ACTIVE_TIME_FOR_SMEARING = 10min`。
- AOSP android-17.0.0_r1：`ScreenPowerStatsProcessor.java` 按 UID top activity duration 占比分摊屏幕功耗，`totalTopActivityDuration == 0` 时跳过 UID 分摊。
- AOSP android-17.0.0_r1：PowerStats AIDL `EnergyConsumerResult.energyUWs` 与 `EnergyMeasurement.energyUWs` 单位为 uWs；`EnergyConsumerType.aidl` 含 `CPU_CLUSTER`、`DISPLAY`、`WIFI` 等类型且无 GPU 专有类型。
- Android Developers PowerMonitor API 文档：`PowerMonitor` / `PowerMonitorReadings` 为 API 35；`getConsumedEnergy()` 返回 since boot 的 uWs。
- Android Studio Power Profiler 文档：ODPM 数据只在 Pixel 6 及后续 Pixel 设备上可用，且为设备级功耗数据。
