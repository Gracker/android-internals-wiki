## 复核证据摘要
- ART Service README：查看编译原因的命令为 `pm art dump <package-name>`；`-dm` 只是表示 install dexopt 时传入 DM 文件，不代表 DM 内容一定被 dex2oat 使用。

- Perfetto heapprofd 文档：推荐 `tools/heap_profile` 或 TraceConfig；heapprofd 数据进入 `heap_profile_allocation` 等表。
- Android API reference /公开资料：`ApplicationExitInfo` 与 `ActivityManager.getHistoricalProcessExitReasons()` 为 Android 11/API30+。
- Coil 官方升级说明：Coil 2.x removes bitmap pooling and related classes。
