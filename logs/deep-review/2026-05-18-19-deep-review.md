## 问题单明细
1. [P0] 2.23 L70-L74：`Window.setFrameRate()` 不存在。证据：android-16.0.0_r1 `current.txt` 中 `Surface#setFrameRate()`、`View#setRequestedFrameRate()`、`SurfaceControl.Transaction#setFrameRate()` 存在；`Window` 只有 `setFrameRateBoostOnTouchEnabled()` / `setFrameRatePowerSavingsBalanced()`。建议替换 API 名称并拆清 Window 策略开关。
2. [P0] 1.8 L174-L190：`TOP_SLEEPING` oom_adj=200 错误。证据：android-16 `OomAdjuster` 在 app==topApp sleeping 分支设置 `FOREGROUND_APP_ADJ` 并标 `adjType=top-sleeping`。建议把 TOP_SLEEPING 移出 oom_adj 表。
3. [P0] 1.8 L286-L307：Service ANR 伪代码仍是旧 Handler 模型。证据：android-16 `ActiveServices.scheduleServiceTimeoutLocked()` 调 `mActiveServiceAnrTimer.start(proc, delay)`。建议替换为 AnrTimer 路径。
4. [P0] 20.3 L100-L113：crash_dump 启动链路错误。证据：android-16 `debuggerd_handler.cpp` 在崩溃进程中 `_Fork()` 并 `execle(CRASH_DUMP_PATH, ...)`；`crash_dump.cpp` 连接 tombstoned 获取输出 fd，并通知 ActivityManager。建议重写链路。
5. [P0] 20.3 L182：tombstone 格式锚点错误。证据：`engrave_tombstone()` 定义在 `system/core/debuggerd/libdebuggerd/tombstone.cpp` / `tombstone_proto.cpp`。建议补 source 并改正文锚点。
6. [P0] 20.3 L285-L301：Breakpad debug-id 协议错误。证据：Breakpad `symbol_files.md` 以 MODULE 行 debug-id 匹配符号文件，示例为 32 位 hex；不应写固定 16 字符或截断前 16 字符。建议使用完整 MODULE debug-id。
7. [P0] 1.8 L332-L334：ANR trace 输出路径过时。证据：android-16 `StackTracesDumpHelper` 使用 `/data/anr/anr_<timestamp>`。建议替换固定 `/data/anr/traces.txt`。
8. [P1] 1.8 L525：Broadcast ANR 计时起点错误。证据：`BroadcastQueueImpl.dispatchReceivers()` 在调度 Receiver 前调用 `startDeliveryTimeoutLocked()`。建议改为调度时启动 delivery timeout。
9. [P1] 1.8 L527-L529：Modern broadcast queue 版本归属需修正。建议区分 Android 14/15 的 `BroadcastQueueModernImpl` 与 Android 16 的 `BroadcastQueueImpl`。
10. [P0] 20.3 L303-L305：Breakpad 源码函数锚点不存在。建议改为 `SimpleSymbolSupplier::GetSymbolFileAtPathFromRoot()` / `BasicSourceLineResolver::Module::LookupAddress()`。
11. [P0] 20.3 L438-L442：`JNIEnv->FindSymbol()` 不存在。建议改为 ART/JNI resolve、`dlsym` 或 `RegisterNatives` 失败路径。
12. [P1] 20.3 L178-L180：`getTraceInputStream()` 返回 tombstone protobuf 且可能为 null，不是 native tombstone 原文。
13. [P1] 20.3 L188-L199：Java/Dex/JIT 帧解析不能归因给 `.eh_frame` CFI。
14. [P1] 20.3 L328-L331：Crashpad signal handler / handler 进程关系需重写。
