  1. `PerformanceHintManager#createHintSession(int[], long)` 返回 `PerformanceHintManager.Session`，API 31 起公开；正文示例使用 `int[] tids`、`reportActualWorkDuration(long)`、`updateTargetWorkDuration(long)`，与 Android Developers API reference 和本地 SDK android-35 源码一致。
