## 证据来源
- AOSP simpleperf doc/README.md：Simpleperf 是 Android native CPU profiler；Android >= P 支持 JIT/interpreted Java callgraph；Android >= Q 支持 profileable from shell。
- AOSP simpleperf doc/android_application_profiling.md：Android >= P 支持 interpreted/JIT/compiled Java；Android O/N 只支持 compiled Java；Android <= M 不支持 Java profiling；profileableFromShell 从 Android >= Q 开始。
- AOSP simpleperf doc/executable_commands_reference.md：record 默认 cpu-cycles、默认 4000 samples/s；--trace-offcpu 只允许 cpu-clock/task-clock，kernel >= 4.2。
- AOSP simpleperf doc/view_the_profile.md 与 Perfetto other-formats：simpleperf proto 导出示例使用 `simpleperf report-sample --show-callchain --protobuf`；Perfetto 文档说明 `--show-callchain` is required to include call stack information.
