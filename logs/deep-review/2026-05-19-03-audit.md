### [P1][版本差异] L94-L99 `GPU_DURATION` / `SWAP_BUFFERS_DURATION` 指标口径缺少 Android 12/13 源码边界
- 证据：
  - `android-12.0.0_r1` / `android-12.1.0_r1`：`GPU_DURATION` 的 `DURATIONS` 端点是 `Index.SWAP_BUFFERS -> Index.GPU_COMPLETED`。
  - `android-13.0.0_r1` 起：`GPU_DURATION` 的端点变为 `Index.COMMAND_SUBMISSION_COMPLETED -> Index.GPU_COMPLETED`。
  - `android-7.0.0_r1` 到 `android-11.0.0_r1`：`SWAP_BUFFERS_DURATION` 的端点是 `Index.SWAP_BUFFERS -> Index.FRAME_COMPLETED`；`android-12.0.0_r1` 起变为 `Index.SWAP_BUFFERS -> Index.SWAP_BUFFERS_COMPLETED`。
- 影响：现文只写 “`GPU_DURATION` API 31+” 和 “`SWAP_BUFFERS_DURATION` Buffer 交换耗时”。读者做 Android 12/12L 与 Android 13+、或 Android 7-11 与 12+ 的线上聚合对比时，容易把不同端点的 raw 时长当成同一口径。
- 建议：在指标表后补版本边界表：API 24-30 无 `GPU_DURATION` / `DEADLINE`，且 `SWAP_BUFFERS_DURATION` 到 `FRAME_COMPLETED`；API 31-32 的 `GPU_DURATION` 为 `SWAP_BUFFERS -> GPU_COMPLETED`；API 33+ 为 `COMMAND_SUBMISSION_COMPLETED -> GPU_COMPLETED`。线上聚合按 API bucket 分开，避免跨这些边界直接比较 GPU/SWAP 原始时长。
