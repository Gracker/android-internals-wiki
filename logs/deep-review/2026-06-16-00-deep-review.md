## 证据来源
- AndroidX Core release notes：core-splashscreen 1.2.0 stable；1.0.0 说明库覆盖 API 23+。
- AndroidX SplashScreen.kt：API<31 实现读取主题、setPostSplashScreenTheme、OnPreDrawListener、SplashScreenViewProvider / dispatchOnExitAnimation。
- Android Developers SplashScreen migration 文档：postSplashScreenTheme 是迁移必填项，dedicated Splash Activity 会导致重复 splash，SplashScreen API 降低 dedicated activity 引入的启动延迟。
- Android Developers ApplicationExitInfo API：API31+ REASON_CRASH_NATIVE tombstone trace，trace 可能因全局循环缓冲区覆盖而返回 null。
- Perfetto SQL docs：同一表同一分区 span 不能重叠，违反时会静默产生错误行；分区需为整数。
