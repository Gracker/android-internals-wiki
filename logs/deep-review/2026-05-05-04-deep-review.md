## Queue issue 详情

### 7.2 卡顿原因体系
1. [P0] [源码错误] L451 Thermal API 类名
   - 问题：`android.os.ThermalManager` 不是可核 public app API；应用侧应使用 PowerManager thermal listener/headroom。
   - 建议：改为 `PowerManager.addThermalStatusListener()` / `PowerManager.OnThermalStatusChangedListener` 与 `PowerManager.getThermalHeadroom()`；如讨论 HAL，单独标 `android.hardware.thermal`。
2. [P1] [版本差异] L343 HWC2 源码索引版本列
   - 问题：`include_all/hardware/hwcomposer2.h` 不是全版本路径，且 Android 5/6 不属于 HWC2。
   - 建议：按 HWC1、HWC2 Android 7-14、HWC2 Android 15+、HWC3 Android 13+ 拆版本。

### 9.2 ANR 类型与触发条件
1. [P0] [源码/原理错误] L233/L279 FGS DidNotStart 结果
   - 问题：正文同时写“最终 ANR”和“Android 12+ crash”，与源码和官方 troubleshooting 的 DidNotStartInTimeException crash 口径冲突。
   - 建议：拆成 serviceForegroundTimeout 入口、ForegroundServiceDidNotStartInTimeException crash、TimeoutRecord/延迟 ANR 诊断处理三层，不要归成单一路径。
2. [P1] [源码准确性] L306 AnrTimer 运行模型
   - 问题：AnrTimer 不是“独立线程中运行”的 Java 计时器；到期后仍向 Handler 投递消息。
   - 建议：改成 native-backed timer + Handler delivery + accept/discard/latency 记录；精度提升需补证据。
