## 证据来源
- Android Developers Simpleperf：命令行 Simpleperf 是 NDK 自带 CPU profiling 工具，完整文档指向 AOSP Simpleperf README（last updated 2026-03-06）。
- AOSP `platform/system/extras` `android16-release` Simpleperf README：Simpleperf 可 profile Java/C++；Android >= P 支持 interpreted/JIT Java callgraph；Android >= Q 支持 `<profileable android:shell="true" />` release app profiling。
- AOSP `android16-release` `executable_commands_reference.md`：`record` 基于 `perf_event_open`；默认 event 为 `cpu-cycles`，默认 4000 samples/s；`--trace-offcpu` 只允许 `cpu-clock` / `task-clock`，依赖 `sched:sched_switch` 与 context switch 记录，kernel >= 4.2 可检查 feature。
- AOSP `android16-release` `scripts_reference.md`：`app_profiler.py -r` 传递 record 参数；`report_html.py` 生成 Chart Statistics / Sample Table / Flamegraph；`gecko_profile_generator.py`、`report_sample.py`、`stackcollapse.py` 分别覆盖 Gecko JSON、perf script、folded stacks 路径。
- Android Developers `<profileable>` manifest 文档：`android:shell` 允许 simpleperf / Perfetto 等本地 profiling，元素 introduced in API 29，`android:enabled` added in API 30。
- Perfetto `other-formats`：simpleperf proto 由 `simpleperf report-sample --protobuf` 生成；导入 Perfetto 时 `--show-callchain` 是包含 call stack 的必要参数。
