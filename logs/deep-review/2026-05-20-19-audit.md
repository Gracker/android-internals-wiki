## 抽检证据
- Android 10 TLS 1.3 官方文档：平台 TLS 1.3 默认启用，但明确写明 “0-RTT mode isn't supported”；Android 10 features 文档只给出 TLS 1.3 相比 TLS 1.2 最多 40% 建连加速。
- `android.net.http.HttpEngine.Builder` 官方 API：`addQuicHint()` 仅说明开启 HTTP cache 后可利用 QUIC 0-RTT connection establishment；Cronet `QuicOptions.Builder.enableTlsZeroRtt()` 只是 QUIC/TLS 0-RTT 开关，未支撑“Android 15 Conscrypt 自动 anti-replay”。
- Android 17 Network Security Configuration 官方文档：ECH 从 Android 17（API 37）可用，默认 `enabled`，应用可全局或按域 opt out / 修改；示例为 `mode="enabled"` 与 `mode="disabled"`。
- Android 17 Advanced Protection Mode 官方文档：描述的是 2G/WEP、sideloading、forensic logging、未知号码来电、消息链接防护等策略，以及 `AdvancedProtectionManager` 状态查询/回调；未发现 ECH/DoH3 强制覆盖 Network Security Config 的公开依据。
- ECH 官方文档与 RFC 9849：ECH 负责加密 ClientHello/SNI；DoH/DoT 只保护 DNS 查询通道，不能隐藏 TLS SNI。
