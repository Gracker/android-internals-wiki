## 核对资料
- Android Developers Microbenchmark 文档：`androidx.benchmark` plugin 默认 full AOT 需要 Benchmark 1.3.0-beta01+ 与 Android Gradle Plugin 8.4.0+；可通过 `androidx.benchmark.forceaotcompilation=false` 关闭。
- Android Developers Macrobenchmark 文档：Macrobenchmark 需要独立 `com.android.test` module；target app 必须 `profileable`；Macrobenchmark 编译状态可通过 `CompilationMode.Full / Partial / None / Ignore` 控制；Android M/API 23 只有 `Full` 支持。
- Android Developers Baseline Profiles 文档：新建 Baseline Profile 推荐 AGP 8.2+ 模板；连接设备生成 profile 需要 rooted 设备或 API 33+；本章把 AGP 7.0+ 写作最低打包能力边界，没有把它写成当前推荐入口。
- AndroidX API reference：`CompilationMode` 在 API 24+ 支持不同编译层级，API 23 only Full；`BaselineProfileRule` 支持 API 33+ 或 rooted API 28+；`BlackHole.consume()` 用于防止 dead-code elimination。
