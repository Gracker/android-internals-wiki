## 证据锚点
- AndroidX Benchmark `Arguments.kt`：`private const val prefix = "androidx.benchmark."`；`iterations = arguments.getBenchmarkArgument("iterations")?.toInt()`，因此 instrumentation key 需要 `androidx.benchmark.iterations`，裸 `iterations` 不是 Benchmark 参数。
- AndroidX Benchmark `Errors.kt`：官方 sample suppression 使用 `testInstrumentationRunnerArguments["androidx.benchmark.suppressErrors"] = "EMULATOR,LOW-BATTERY"`。
- Coil 2.x upgrade/changelog：`BitmapPool` 和 `PoolableViewTarget` 已从 2.x 移除，不能把当前 Coil 写成 Bitmap Pool 模型。
- AOSP `ComponentCallbacks2.java`（android-16.0.0_r1）：`TRIM_MEMORY_RUNNING_*`、`TRIM_MEMORY_MODERATE`、`TRIM_MEMORY_COMPLETE` 标注 `@Deprecated Apps are not notified of this level since API level 34`；`TRIM_MEMORY_BACKGROUND` 与 `TRIM_MEMORY_UI_HIDDEN` 无该弃用说明。
- Android 16KB page size 官方文档：NDK r28+ 默认构建 16KB-aligned shared libraries；NDK r27 及以下需 `-Wl,-z,max-page-size=16384` 等；AGP 8.5.1+ 才是官方推荐的打包/对齐边界。Google Play 要求自 2025-11-01 起适用于提交到 Play、面向 Android 15+ 设备的新应用和更新。
