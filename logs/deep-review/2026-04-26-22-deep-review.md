  2. [P0] Pipeline Barrier 与 Image Layout / `vkCmdPipelineBarrier` 示例 — 从 `COLOR_ATTACHMENT_OPTIMAL` 转到 `PRESENT_SRC_KHR` 的示例使用 `.dstAccessMask = VK_ACCESS_MEMORY_READ_BIT`，但 `dstStageMask` 写的是 `VK_PIPELINE_STAGE_BOTTOM_OF_PIPE_BIT`。BOTTOM_OF_PIPE 不执行 memory read，把 READ access mask 配到这里会触发 Vulkan validation 或造成同步语义误导。 建议：旧同步写法改为 `dstAccessMask = 0` + `dstStageMask = VK_PIPELINE_STAGE_BOTTOM_OF_PIPE_BIT`；若使用 synchronization2，可写 `dstStageMask = VK_PIPELINE_STAGE_2_NONE` / `dstAccessMask = 0`。同时说明 present 侧依赖 `vkQueuePresentKHR` 等待的 semaphore。
