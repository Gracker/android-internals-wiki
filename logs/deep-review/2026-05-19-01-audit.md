## 审查结果

### 维度 1：源码引用准确性
- 评分：2/5
- 结论：memtrack、Perfetto heapprofd、Macrobenchmark MemoryUsageMetric、Android 14 graphics buffer cache 等锚点基本可复核；Native 调试工具命令和 largeHeap/PSS 指标口径存在高风险错误。
- 已复核源码/官方锚点：
  - bionic malloc_debug README：支持 `backtrace`、`backtrace_enable_on_signal`、`backtrace_dump_on_exit` 等选项；未发现 `enable_on_start`；`libc.debug.malloc.program` 示例匹配 executable（`ls`、`app_process`），App 开发侧推荐 wrap.sh / `wrap.<APP>`。
  - Android API reference：`Debug.MemoryInfo.getTotalPss()` 返回 total PSS kB；`ActivityManager.getLargeMemoryClass()` 返回 large heap 下的 approximate per-application memory class。
  - AndroidX API reference：`MemoryUsageMetric` 存在，Added in 1.2.0，构造 `MemoryUsageMetric(MemoryUsageMetric.Mode.Max)` 可成立但属于 `@ExperimentalMetricApi`。
- 具体问题：
  1. [P0][源码准确性] lines 237-245 — malloc debug 示例使用 `libc.debug.malloc.program com.example.app` 和 `backtrace enable_on_start`。`enable_on_start` 不是官方 malloc_debug option；`program` 不是 package 选择器，官方 App 场景应走 wrap.sh / `wrap.<APP>` + `LIBC_DEBUG_MALLOC_OPTIONS`。
  2. [P1][源码准确性] lines 413-415、428 / line 81 — PSS 被写成可按 `largeHeap` 上限计算比例。PSS 是进程总常驻分摊，largeHeap/memoryClass 是 Java heap 预算，两个指标不能直接相除作为线上触发阈值。

### 维度 3：版本差异覆盖
- 评分：3/5
- 结论：Android 12 DMA-BUF/GPU accounting、Android 14 per-layer buffer cache purge、Android 15/16 16KB page size 口径基本成立；ASan 与 Bitmap 历史分段存在版本边界问题。
- 已复核版本点：
  - Android 14 Reduce graphics memory consumption：GraphicBufferProducer disconnect 后可清理 Composer HAL / SurfaceFlinger 间 per-layer buffer cache；完整收益依赖 Composer HAL 3.2。
  - Android 12 DMABUF/GPU accounting：`getMemory(PID 0, MemtrackType::GL)` + `FLAG_SMAPS_UNACCOUNTED` 用于 global total GPU-private memory。
  - Android Bitmap docs：API 10 及以下 pixel data 在 native memory；API 11-25 在 Dalvik heap；API 26+ 在 native heap。
  - Android NDK ASan docs：AddressSanitizer beginning with API level 27 (Android O MR1)。
- 具体问题：
  1. [P1][版本差异] line 253 — “Android 8.0 开始支持在非 root 设备上使用 ASan”应改为 API 27 / Android 8.1 (O MR1) 起，并说明 debuggable + wrap.sh 约束。
  2. [P2][版本差异] line 279 — “Android 8.0 之前 Bitmap 像素数据存储在 Java Heap”覆盖过宽；API 10 及以下实际在 native memory，API 11-25 才在 Dalvik heap。
