## 复核依据

- Android Developers `DnsResolver`：`TYPE_HTTPS`、`HTTPS_QUERY_WAIT_*` 与并发 A/AAAA/HTTPS `query(..., httpsTimeoutMillis, ..., Callback<HttpsEndpoint>)` 均标注 API 37 / S Extensions 22。
- Android Developers `HttpsRecord` / `HttpsEndpoint`：`getAlpnIds()`、`getEchConfigList()`、`getIpAddressHints()`、`getHttpsRecords()`、`getIpAddresses()` 均标注 API 37 / S Extensions 22。
- Android Developers `HttpEngine.Builder`：`addQuicHint()`、`setEnableQuic()`、`setEnableHttp2()` 标注 API 34 / S Extensions 7；`setProxyOptions()` 为 API 37，不影响正文现有边界。
- Android Developers Android 10 TLS 行为：TLS 1.3 默认启用，标准平台 TLS 明确不支持 0-RTT。
- source.android Mainline / DNS Resolver / Conscrypt：`com.android.resolv` 与 `com.android.conscrypt` 均为 Android 10 引入的 APEX 模块；DNS Resolver 模块支撑 `InetAddress#getAllByName`、`Network#getAllByName` 与 native networking functions。
- Google Online Security Blog 2022-07：DoH3 通过 Google Play system update 覆盖 Android 11+，部分较早采用 Play system update 的 Android 10 设备也可获得；成功查询中 median 降 24%、P95 降 44%。
- OkHttp 4.12.0 `ConnectionPool.kt` 与 OkHttp 5.x Builder protocols / Protocol docs：默认连接池 5 idle / 5 minutes 成立；Builder protocols 当前公开支持 `http/1.1`、`h2`、`h2 prior knowledge`，HTTP/3 仍不能按稳定原生客户端能力写。
- RFC 9460：HTTPS/SVCB RR 用于在建连前提供服务端点与参数，如 ALPN、IP hints、ECH 配置；正文 Type 65 总方向成立。

## 审查结果

### 维度 1：源码引用准确性 / API 可用性

- 评分：4.7/5
- 问题数：P0 0 / P1 0 / P2 0 / P3 1

1. [P3] L157-L163 OkHttp `ConnectionPool` 代码块 — 正文验证口径写 OkHttp 4.12.x，但代码块注释仍写 `okhttp3/ConnectionPool.java` 且 fence 为 `java`。OkHttp 4.12.0 对应源码是 `okhttp/src/main/kotlin/okhttp3/ConnectionPool.kt`，语义与默认值成立，只是源码文件类型/路径提示偏旧。
   - 建议：后续编辑时把注释改成 `okhttp/src/main/kotlin/okhttp3/ConnectionPool.kt`，代码块改为 Kotlin 或改写成 API 摘要；无需回炉。

### 维度 3：版本差异覆盖

- 评分：4.6/5
- 问题数：P0 0 / P1 0 / P2 0 / P3 1

1. [P3] L308-L312 DNS HTTPS Record 性能收益表述 — Android API 37 / S Extensions 22 的 `DnsResolver` / `HttpsRecord` / `HttpsEndpoint` 边界成立；正文“省掉 1-2 个探测 RTT”的方向基本合理，但 ALPN 在 TLS/QUIC 握手中并非独立额外 RTT，ECH 配置也不是建连后再单独协商。更严谨的写法应落到“支持栈可在建连前获取 ALPN、IP hints、ECH 配置，减少 Alt-Svc 首次探测、地址提示补查或失败重试带来的额外往返”。
   - 建议：后续版本可收窄表述，避免把 Type 65 写成所有客户端栈都会稳定节省 1-2 RTT 的平台保证；当前已有限定为 API 37 且未越过 Android 17，暂不回炉。
