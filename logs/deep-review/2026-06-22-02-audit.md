## 审查结果

### 维度 1：源码引用准确性
- 评分：5/5
- 问题数：0
- 复核通过：
  1. AOSP `android-17.0.0_r1` 中 `frameworks/base/graphics/java/android/graphics/RenderEffect.java` 存在 `createBlurEffect()`、`createChainEffect()`、`createRuntimeShaderEffect(RuntimeShader, String)`；后者注释明确把安装 RenderEffect 的 RenderNode 内容作为 shader 输入。
  2. AOSP `android-17.0.0_r1` 中 `frameworks/base/core/java/android/view/View.java` 的 `setRenderEffect()` 调用 `mRenderNode.setRenderEffect()`，变化时执行 `invalidateViewProperty(true, true)`；`setBackdropRenderEffect()` 仍带 `@hide`，章节对 backdrop effect 的隐藏 API 边界成立。
  3. AOSP `android-17.0.0_r1` 中 `RenderNode.setRenderEffect()` 注释仍说明 blur 会让内容先绘制到 separate layer，再对该 layer 做模糊处理；章节离屏层成本描述成立。
  4. AOSP `android-17.0.0_r1` 中 `RuntimeShader.setFloatUniform()` 只更新 shader builder / native uniforms，不会触发 View 属性失效；章节要求 uniform 更新后显式 `postInvalidateOnAnimation()` 的口径成立。
  5. Android Developers API reference 确认 `RenderEffect` API 31、`RuntimeShader` 构造与基础 uniform API 33、`createRuntimeShaderEffect()` API 33、`SystemHealthManager.getGpuHeadroom()` API 36，并列出 `UnsupportedOperationException` 与最小采样间隔相关 API。

### 维度 3：版本差异覆盖
