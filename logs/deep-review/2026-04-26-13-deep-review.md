## 证据锚点
- source.android.com HWC：SurfaceFlinger 调 `validateDisplay()`，必要时 GPU fallback 合成 client target，再 `setClientTarget()`、`presentDisplay()` 交给 HWC 完成最终输出。
- AOSP android-16-release `GraphicsEnvironment.java`：`queryAngleChoice()`、`ANGLE_GL_DRIVER_ALL_ANGLE_ON = 1`、`config_angleAllowList`。
- AOSP android-16-release `graphics/composer3/Capability.aidl`：`SKIP_VALIDATE = 4`，注释说明可跳过 `validateDisplay` 先尝试 `presentDisplay`。
- Flutter Impeller 官方文档：3.27 起 Android API 29+ 默认启用 Impeller；低版本或无 Vulkan 支持时回退到 legacy OpenGL renderer。
- Flutter Platform Views 官方文档：Hybrid Composition / Texture Layer Hybrid Composition 的性能取舍、SurfaceView 与 Text Magnifier 边界。
