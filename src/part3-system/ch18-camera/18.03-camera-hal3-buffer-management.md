## 18.3.1 Camera HAL3 Buffer 基础架构

### 18.3.1.1 HAL3 Buffer 概念模型

Camera HAL3 的 Buffer 管理基于以下核心概念：

- **GraphicBuffer**：Android 图形缓冲区的抽象表示，包含像素数据、元数据及内存映射信息
- **BufferQueue**：生产者-消费者模式的缓冲队列，管理多个 Buffer 的流转
- **Request**：包含 Buffer 请求参数及回调接口的封装对象
- **Stream**：数据流抽象，定义 Buffer 的格式、尺寸等属性

```cpp
// AIDL Camera HAL3 Buffer 概念模型
@VintfStability
interface ICameraDevice3 {
    // Buffer 请求接口
    void submitRequest(in Camera3Request request, boolean streaming);
    
    // Buffer 配置接口

    // Buffer 状态通知
    void notify(in Camera3Notification notification);
}
```

### 18.3.1.2 Buffer 内存分配策略

Camera HAL3 采用分层内存分配策略：

1. **预分配层**：应用启动时预先分配一组 Buffer，减少运行时分配开销
2. **动态分配层**：根据请求需求动态分配 Buffer，应对突发流量
3. **缓存层**：使用 Buffer 池技术复用已分配的 Buffer，减少内存碎片


## 18.3.2 BufferQueue 协作机制

### 18.3.2.1 生产者-消费者模式

Camera HAL3 作为 BufferQueue 的生产者，Camera 客户端作为消费者，形成完整的 Buffer 流转链路：

```
[App] -> [Camera Client] -> [Camera HAL3] -> [Hardware Driver] -> [Sensor]
       ↑                   ↑                   ↑
    Consumer           Producer           BufferQueue
```

### 18.3.2.2 Buffer 请求与分配流程

完整的 Buffer 请求流程包括：

1. **请求阶段**：应用通过 Camera2 API 发起 Buffer 请求
2. **分配阶段**：HAL3 根据请求参数分配或复用 Buffer
3. **填充阶段**：硬件将图像数据写入 Buffer
4. **回调阶段**：通过 Surface 或回调接口通知应用 Buffer 就绪
5. **释放阶段**：应用使用完毕后将 Buffer 归还队列

```cpp
// Camera HAL3 Buffer 请求处理流程
status_t Camera3Device::processRequest(const sp<Camera3Request>& request) {
    // 1. 验证请求参数
    if (request->mSettings == nullptr) {
        return BAD_VALUE;
    }
    
    // 2. 分配 Buffer
    for (auto& output : request->mOutputStreams) {
        sp<Camera3Buffer> buffer;
        status_t ret = getBuffer(output, &buffer);
        if (ret != OK) {
            return ret;
        }
        request->mOutputBuffers.add(output, buffer);
    }
    
    // 3. 提交到硬件
    return submitRepeatingRequests(request);
}
```

### 18.3.2.3 Buffer 状态机

Camera HAL3 Buffer 具有明确的状态转换关系：

- **FREE**：Buffer 可用状态，等待分配
- **ALLOCATED**：已分配但未使用
- **IN_USE**：正在被硬件写入数据
- **READY**：数据填充完成，等待消费
- **ACQUIRED**：已被应用获取，等待处理
- **RELEASED**：已释放，返回 FREE 状态

```cpp

    BUFFER_STATE_ACQUIRED,    // 已获取
    BUFFER_STATE_RELEASED    // 已释放
};

class Camera3Buffer : public RefBase {
private:
    BufferState mState;
    sp<GraphicBuffer> mGraphicBuffer;
    
    void transitionState(BufferState newState) {
        // 状态转换验证

        }
```

## 18.3.3 内存管理与优化策略

### 18.3.3.1 内存碎片控制

Camera HAL3 采用多种策略控制内存碎片：

1. **固定尺寸 Buffer 池**：预分配固定尺寸的 Buffer，避免动态分配碎片
2. **尺寸对齐优化**：Buffer 尺寸按 16 或 32 字节对齐，提高内存利用率
3. **内存池复用**：使用相同格式的 Buffer 池，减少内存碎片

```cpp
// Camera HAL3 内存池实现
class Camera3MemoryPool {
    std::map<int, std::vector<sp<GraphicBuffer>>> mPools;
    
    sp<GraphicBuffer> getBuffer(int width, int height, int format) {
        // 1. 查找匹配的 Buffer 池
        int poolKey = getPoolKey(width, height, format);
        
        // 2. 从池中获取
        if (!mPools[poolKey].empty()) {
            sp<GraphicBuffer> buffer = mPools[poolKey].back();
            mPools[poolKey].pop_back();
            return buffer;
        }
        
        // 3. 池为空时创建新 Buffer
        return createNewBuffer(width, height, format);
    }
    
    void returnBuffer(sp<GraphicBuffer> buffer) {
        // 归还 Buffer 到对应的池
        int poolKey = getPoolKey(buffer->getWidth(), buffer->getHeight(), buffer->format);
        mPools[poolKey].push_back(buffer);
    }
};
```

### 18.3.3.2 内存访问优化

为提高 Buffer 访问性能，Camera HAL3 实现了以下优化策略：

1. **内存映射优化**：使用 `mmap` 将 Buffer 映射到进程地址空间，减少数据拷贝
2. **缓存友好访问**：将 Buffer 数据按照缓存行大小对齐，提高缓存命中率
3. **DMA 传输优化**：直接通过 DMA 将硬件数据写入 Buffer，避免 CPU 中间环节

```cpp
// Camera HAL3 内存映射优化
class Camera3BufferMapping {
    void* mapBuffer(sp<GraphicBuffer> buffer) {
        // 内存映射参数
        void* mapped = buffer->getNativeBuffer()->lock(
            GRALLOC_USAGE_SW_READ_OFTEN | GRALLOC_USAGE_SW_WRITE_OFTEN,
            &mBounds);
        
        if (mapped) {
            // 检查内存对齐
            size_t alignment = getCacheLineSize();
            uintptr_t addr = reinterpret_cast<uintptr_t>(mapped);
            
            if (addr % alignment != 0) {
                ALOGW("Buffer address not cache-aligned: %p", mapped);
            }
            
            // 设置访问模式
            setupCacheFriendlyAccess(mapped, buffer->getSize());
        }
        
        return mapped;
    }
};
```

### 18.3.3.3 内存使用监控

1. **Buffer 计数监控**：实时监控 Buffer 使用数量、分配/释放频率
2. **内存使用统计**：统计 Buffer 总内存占用、平均 Buffer 大小

```cpp
// Camera HAL3 内存监控实现
class Camera3BufferMetrics {
    struct BufferStats {
        int totalBuffers;
        size_t totalMemory;
        double avgAllocationTime;
        double avgAccessTime;
        int64_t lastAllocationTime;
    };
    
    std::map<int, BufferStats> mStreamStats;
    
    void recordAllocation(int streamId, size_t bufferSize, duration allocationTime) {
        BufferStats& stats = mStreamStats[streamId];
        stats.totalBuffers++;
        stats.totalMemory += bufferSize;
        stats.avgAllocationTime = 
            (stats.avgAllocationTime * (stats.totalBuffers - 1) + 
             allocationTime.count()) / stats.totalBuffers;
    }
    
    void reportMetrics() {
        for (auto& [streamId, stats] : mStreamStats) {
            ALOGI("Stream %d: %d buffers, %zu bytes total, avg alloc: %.2f ms",
                  streamId, stats.totalBuffers, stats.totalMemory,
                  stats.avgAllocationTime);
        }
    }
};
```

### 18.3.5.1 Buffer 泄漏检测

```cpp
// Camera HAL3 Buffer 泄漏检测
class Camera3BufferLeakDetector {
    std::set<sp<Camera3Buffer>> mActiveBuffers;
    
    void trackBufferAllocation(sp<Camera3Buffer> buffer) {
        mActiveBuffers.insert(buffer);
        ALOGV("Buffer allocated, active count: %zu", mActiveBuffers.size());
    }
    
    void trackBufferRelease(sp<Camera3Buffer> buffer) {
        auto it = mActiveBuffers.find(buffer);
        if (it != mActiveBuffers.end()) {
            mActiveBuffers.erase(it);
            ALOGV("Buffer released, active count: %zu", mActiveBuffers.size());
        } else {
            ALOGW("Attempt to release unknown buffer");
        }
    }
    
    void checkForLeaks() {
        if (!mActiveBuffers.empty()) {
            ALOGE("Potential buffer leak detected: %zu buffers still active",
                  mActiveBuffers.size());
            
            for (auto buffer : mActiveBuffers) {
                ALOGI("Leaked buffer: %p, size: %zu, refcount: %d",
                      buffer.get(), buffer->getSize(), buffer->getStrongCount());
            }
        }
    }
};
```
