# Android 17 启动框架与任务编排 — ApplicationStartInfo 与 AppStartInfoTracker

<!-- outline-start -->
## 要点

### 🔹 GPU功耗管理基础
Android 17 引入了全新的 GPU 功耗管理策略，基于 DVFS（动态电压频率调节）机制的深度优化。

### 🔹 DVFS 调优算法
新算法结合了应用负载预测和系统资源监控，实现了更智能的频率和电压调节。

### 🔹 多核心协调机制
跨 GPU 核心的功耗分配协调，根据不同应用场景动态调整核心工作状态。

### 🔹 热量控制与性能平衡
在控制 GPU 发热的同时保持最佳的性能表现，引入了热量感知的调度策略。

### 🔹 SoC 厂商定制化
支持不同 SoC 厂商的定制化 DVFS 策略，充分发挥硬件性能潜力。

## 扩展

### 🔸 游戏场景优化
针对游戏场景的特殊功耗优化策略，平衡帧率和功耗的关系。

### 🔸 AI 推理任务
AI 推理任务在 GPU 上的功耗管理，考虑模型大小和推理频率的影响。

### 🔸 后台任务处理
后台 GPU 任务的功耗管理策略，避免不必要的资源占用。

## 源码级深度调研（Android 17 Boot Timing 优化）

基于 AOSP android-17.0.0_r1 源码的启动性能监控机制调研发现：

### 1. ApplicationStartInfo 时间戳架构

Android 17 引入完整的启动时间标记体系，涵盖：

- **START_TIMESTAMP_FORK**: 进程分叉时间 (ProcessList.java:2681)
- **START_TIMESTAMP_BIND_APPLICATION**: bindApplication 调用时间 (AMS.java:5497)
- **START_TIMESTAMP_APPLICATION_ONCREATE**: onCreate 调用时间 (AMS.java:5761)
- **START_TIMESTAMP_FIRST_FRAME**: 首帧绘制时间
- **START_TIMESTAMP_FULLY_DRAWN**: 完全绘制时间
- **START_TIMESTAMP_INITIAL_RENDERTHREAD_FRAME**: 渲染线程首帧 (ViewRootImpl.java:5064)
- **START_TIMESTAMP_SURFACEFLINGER_COMPOSITION_COMPLETE**: SF 合成完成 (AMS.java:10955)

### 2. AppStartInfoTracker 数据管理

AppStartInfoTracker 采用容器化管理启动信息：

- **数据结构**: AppStartInfoContainer 按包名/UID 存储 ApplicationStartInfo
- **持久化**: 30 分钟间隔 + 14 天历史数据
- **状态转换**: 首帧绘制时触发 STARTUP_STATE_FIRST_FRAME_DRAWN
- **API 接口**: addApplicationStartInfoCompletionListener + addStartInfoTimestamp

### 3. 启动温度分类系统

- **冷启动 (TEMPERATURE_COLD)**: 新进程创建
- **温启动 (TEMPERATURE_WARM)**: 进程复用，Activity 重建  
- **热启动 (TEMPERATURE_HOT)**: Activity 前台复用

### 4. 性能监控集成

- **PSI 监控**: startPsiMonitoringAfterBoot() 启动进程统计监控
- **实时追踪**: ActivityMetricsLaunchObserver 启动序列回调
- **监控模式**: 支持详细监控模式切换
- **API 可观测**: 公开 addStartInfoTimestamp 接口供框架调用

### 5. 关键调用链

启动时间捕获完整调用链：
```
ActivityMetricsLaunchObserver.onActivityLaunchFinished() 
  → AppStartInfoTracker.onActivityLaunchFinished()
    → AppStartInfoContainer.addTimestampToStartLocked()
      → ApplicationStartInfo.addStartupTimestamp()
```

这些机制为 Android 17 启动性能分析提供了完整的底层支持。
