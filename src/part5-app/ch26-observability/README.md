# 第 26 章：应用可观测性

第 19 章详细拆解了 APM 工具生态和监控 SDK 的实现原理，第 15 章讨论了方法论和指标体系。

本章站在 App 团队的视角，讨论如何搭建完整的应用可观测性体系。从 Crash 上报到性能采集，从线上排查到发版门禁，覆盖「发现问题 - 定位问题 - 解决问题 - 防止复发」的完整闭环。

- 26.13 ApplicationStartInfo 与启动归因上报
