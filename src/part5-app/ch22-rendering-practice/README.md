# 第 22 章：渲染优化实战

第 2 章和第 18 章从系统侧拆解了渲染管线的每一个环节，第 7 章则系统性地分析了卡顿的成因与方法论。

本章换一个视角：站在 App 开发者的工位上，讨论日常开发中如何写出流畅的 UI。从布局优化到 RecyclerView 调优，从 Compose 性能到 WebView 治理，每一节都是可以直接落地的实战指南。

- 22.1 布局优化策略
- 22.2 RecyclerView 最佳实践
- 22.3 Jetpack Compose 性能优化
- 22.4 自定义 View 性能优化

- 22.7 WebView 性能优化实战
- 22.8 帧率监控与线上卡顿治理
- 22.9 渲染优化案例集
