# 22.29 Jetpack Compose 并发安全机制

<!-- outline-start -->
## 要点

### 🔹 双锁架构设计
Jetpack Compose 采用双锁架构保证并发安全：Snapshot 全局 lock 串行化 modified set 合并，Recomposer stateLock 保护状态机。两个锁相互配合，既保证了线程安全，又避免了过度锁竞争。

### 🔹 Snapshot 全局锁机制
Snapshot 全局 lock 负责串行化处理多个修改的合并操作，确保在并发环境下状态的一致性和正确性。锁的粒度和持有时间是性能关键因素。

### 🔹 Recomposer 状态机保护
Recomposer 的 stateLock 保护状态机的完整生命周期，包括状态转换、状态变更通知等关键操作，确保在并发环境下的状态机正确性。

### 🔹 多 Recomposer 实例隔离与共享
多 Recomposer 实例通过独立的 effectCoroutineContext 实现隔离，但共享全局 Snapshot。这种设计既保证了并发性，又维持了数据一致性。

### 🔹 线程安全优化策略
Compose 深入研究了并发场景下的性能优化，包括锁的细粒度划分、无锁数据结构的运用、以及批量操作的高效实现等并发安全优化技术。
