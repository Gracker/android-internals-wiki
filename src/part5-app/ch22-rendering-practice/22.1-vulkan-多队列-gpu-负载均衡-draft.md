# 22.1 Android 17 Vulkan 多队列并行渲染与 GPU 负载均衡

<!-- outline-start -->
## 要点

### 🔹 双队列强制要求
Android 17 HWUI Vulkan 后端强制要求同一 graphics queue family 申请 2 个 queue：mGraphicsQueue 和 mAHBUploadQueue，分别服务 RenderThread 和 GrallocUploadThread。

### 🔹 线程分工明确
mGraphicsQueue 服务 RenderThread 进行图形渲染，mAHBUploadQueue 服务 GrallocUploadThread 进行缓冲区上传，实现渲染流水线并行化。

### 🔹 独立资源管理
两个 queue 共享 VkDevice 但各自独立 GrDirectContext 与 VMA（Virtual Memory Allocator），确保资源隔离和并行处理。

### 🔸 VK_EXT_global_priority 默认关闭
为性能考虑，VK_EXT_global_priority 默认关闭，避免全局优先级对多队列性能的干扰，保持独立的队列优先级控制。

### 🔸 GPU 负载均衡策略
双队列设计通过独立处理渲染和上传任务，实现 GPU 负载均衡，减少主线程阻塞，提升整体渲染性能。

### 🔸 渲染流水线优化
并行处理架构减少了渲染流水线各阶段的等待时间，特别是对包含大量缓冲区操作的应用效果明显。
