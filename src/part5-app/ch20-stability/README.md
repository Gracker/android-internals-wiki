# 第 20 章：应用稳定性治理

如果说性能优化关注的是「快不快」「顺不顺」，那稳定性治理关注的就是「会不会崩」「能不能用」。

一个 App 的稳定性直接决定了用户留存和业务可用性。Crash、ANR、OOM 是稳定性的三座大山，每一座都需要从分类、监控、治理、度量四个维度系统性地建设。

与第 9 章从系统侧讲 ANR 机制不同，本章站在 App 开发者的视角，讨论如何建立稳定性治理体系、如何分析和修复各类崩溃、如何量化治理效果。
