# 第 24 章：I/O 与网络优化

第 6 章讲了存储与 I/O 的系统机制，第 12 章从系统视角分析了网络性能。

本章站在 App 开发者的视角，讨论文件读写、数据库操作、序列化选型到网络架构的完整 I/O 链路优化。每个 App 都离不开数据的存取和传输，这些看似基础的操作往往是 ANR 和性能瓶颈的隐藏根源。

## 本章内容

- 24.1 文件 I/O 优化
- 24.2 数据库性能优化（SQLite/Room）
- 24.3 序列化性能对比与选型
- 24.4 网络架构与连接管理
- 24.5 网络协议优化（HTTP/2、HTTP/3、gRPC）
- 24.6 数据压缩与缓存策略
- 24.7 离线优先架构
- 24.8 I/O 与网络优化案例集

## 阅读建议

- 如果你关注某个特定问题，可以直接跳到对应小节。
- 每一节都尽量自包含，但建议先通读第一节建立全局认知。
- 案例集放在最后，适合在掌握方法论后对照学习。
