# 第 23 章：内存优化实战

第 4 章从系统侧讲了 Android 内存管理的全貌，第 10 章则聚焦内存性能分析的方法论。

本章站在 App 开发者的视角，讨论日常开发中如何治理内存问题。从泄漏检测到 Bitmap 优化，从 Native 内存到 Java Heap 调优，覆盖 App 内存优化的完整实战体系。

## 本章内容

- 23.1 内存泄漏检测与治理
- 23.2 Bitmap 与图片内存优化
- 23.3 Native 内存管理与优化
- 23.4 Java Heap 优化策略
- 23.5 内存抖动与 GC 治理
- 23.6 大内存与多进程策略
- 23.7 内存监控与线上治理
- 23.8 内存优化案例集

## 阅读建议

- 如果你关注某个特定问题，可以直接跳到对应小节。
- 每一节都尽量自包含，但建议先通读第一节建立全局认知。
- 案例集放在最后，适合在掌握方法论后对照学习。
