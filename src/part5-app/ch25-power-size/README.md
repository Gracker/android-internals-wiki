# 第 25 章：功耗与包体积优化

第 5 章和第 11 章从系统侧讲了 CPU 调度、功耗模型和系统级功耗管理，第 12 章也涉及了 APK 体积。

本章聚焦 App 开发者最关心的两个「减法」问题：如何降低 App 的功耗，如何缩小 App 的体积。这两个维度虽然看起来不如启动和流畅性那样直观，但对用户留存和分发转化率有着决定性影响。

## 本章内容

- 25.1 功耗诊断与分析方法
- 25.2 后台功耗治理
- 25.3 WakeLock 与 Alarm 管理
- 25.4 WorkManager 实战与后台任务调度
- 25.5 定位与传感器功耗优化
- 25.6 APK 体积分析与瘦身
- 25.7 R8 与资源优化
- 25.8 App Bundle 与按需分发
- 25.9 功耗与包体积案例集

## 阅读建议

- 如果你关注某个特定问题，可以直接跳到对应小节。
- 每一节都尽量自包含，但建议先通读第一节建立全局认知。
- 案例集放在最后，适合在掌握方法论后对照学习。
