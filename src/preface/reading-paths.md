# 阅读路径推荐

可以先根据自己的角色和当前问题找到一条主线，再按需补前置章节。首次系统学习时也可以按第一部分到第三部分的顺序阅读。

## App 性能优化工程师

App 层性能优化可以从问题和工具出发，再按需补充系统机制。

**核心路径**：7.1-7.7（流畅性）→ 8.1-8.6（响应速度）→ 9.1-9.5（ANR）→ 13.1-13.5（Perfetto 基础）→ 15.1-15.3（方法论）

这条路径先解决问题分类、trace 阅读和证据判断，再用 `2.4`、`2.5`、`4.5`、`10.x` 补充渲染与内存机制。

**按需深入**：2.4-2.5（渲染管线细节）→ 4.5（App 内存优化）→ 10.1-10.6（内存性能）→ 11.2（App 耗电优化）→ 12.1-12.2（包体积与网络）

## Android Framework / 系统工程师

系统级开发或 ROM 定制适合先顺序阅读前半部分，后续性能问题会反复引用这些系统机制。

**核心路径**：1.1-1.6（架构全景）→ 2.1-2.10（完整渲染路径）→ 3.1-3.3（输入系统）→ 4.1-4.6（内存管理）→ 5.1-5.7（CPU 调度）→ 6.1-6.4（存储 I/O）

这条路径先建立系统对象、进程与线程、数据流和资源管理的整体关系。阅读第 `16`、`17` 章时，便能分清 AOSP 公共机制、Android Common Kernel 基线与厂商定制策略。

**进阶路径**：16.1-16.3（AOSP 优化）→ 17.1-17.3（厂商实践）→ 13.6-13.7（Perfetto 高级用法）

## 性能测试工程师

性能测试、质量平台或线上监控方向可以连续阅读分析方法、指标和工具章节。

**核心路径**：15.3（性能指标体系）→ 15.6（测试最佳实践）→ 13.1-13.4（Perfetto）→ 14.1-14.7（其他工具）→ 15.4（竞品分析）→ 15.5（线上监控）

这条路径先说明该测什么、怎样采集、怎样验证和怎样追踪修复结果，再回到卡顿、启动与 ANR 场景做专项分析。

**场景深入**：7.3（卡顿分析方法论）→ 8.2（启动全流程）→ 9.3（ANR 分析方法）

## 按问题查阅

| 问题 | 去看 |
|------|------|
| 列表滑动卡顿 | 7.4 → 7.5 → 7.7 |
| App 启动慢 | 8.2 → 8.3 |
| ANR 频繁 | 9.2 → 9.3 → 9.4 |
| 内存持续增长 | 10.2 → 10.3 → 10.6 |
| 耗电量高 | 11.1 → 11.2 |
| 不知道怎么看 Perfetto | 13.1 → 13.2 → 13.3 |
| 区分系统问题还是 App 问题 | 15.2 |

带着实际问题阅读时，先把现象对应到正确章节，再补背景与版本差异。章节里的平台源码默认锚定 `android-17.0.0_r1`，内核源码默认锚定 `android17-6.18-2026-06_r6`；若设备版本更低，应按正文给出的版本边界切换到相应历史 tag。
