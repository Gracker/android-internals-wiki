# 作者简介

高建武。网上多用 **Gracker**，也有人叫高爷。人在成都，做 Android 系统开发优化，以及应用侧的快、省、稳。长期看的是 Framework、APM 和系统优化；App 开发和 Linux 也接触，深度不如前面几块。

业余时间写在 [androidperformance.com](https://www.androidperformance.com/)。现在还在更新的系列主要是：

1. **Systrace**：用 Systrace 把系统运行机制和性能问题放到同一条时间线上。
2. **Perfetto**：Google 用来接替 Systrace 的分析工具，多了 SQL 和更完整的数据面。
3. **性能分析和实战**：具体卡顿、ANR、内存、功耗问题怎么采、怎么看、怎么收束。
4. **快省稳**：流畅性、响应速度、内存、稳定性、功耗的基础知识、案例和工具。

这本书把这些题目收进同一套 Android 17 目录。机制不是作者发明的，Zygote、Binder、SurfaceFlinger、LMKD、Perfetto SQL 都在公开系统里。作者做的是按固定源码标签核对、写清边界，并欢迎读者改。
