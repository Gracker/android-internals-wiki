# 适用读者

这本书不是为“刚学会写第一个 Activity”的读者准备的。它更适合下面几类人：

## 1. 有一定 Android 开发经验的应用工程师

如果你已经写过一段时间 App，做过页面、列表、启动、图片、网络、数据库这些常见开发工作，那么这本书里的大部分内容都能直接对上日常问题。你不一定需要先懂 AOSP，但至少要对主线程、View、RecyclerView、Handler 这些概念不陌生。

## 2. 性能优化工程师

如果你现在的工作经常围绕“卡顿、启动、ANR、内存、功耗”打转，这本书会更像一本工作手册。它既想讲原理，也想保留足够多的 trace、路径、指标和判断方式，帮助读者在真实场景里落手。

## 3. Android Framework / 系统工程师

如果你的工作更靠近 Framework、SystemUI、ROM、芯片平台、调度和图形栈，这本书前半部分的价值会更高。尤其是渲染、输入、内存、调度、功耗这些章节，会更接近系统视角。

## 4. 测试、质量和基础架构同学

如果你不一定每天写业务代码，但需要理解性能问题怎么出现、怎么被度量、怎么进入治理闭环，这本书后半部分的方法论、工具和线上监控章节会更有帮助。

## 不太适合的读者

如果你刚开始接触 Android，很多基础概念还没有建立，这本书会有点陡。它默认读者已经见过常见组件、知道主线程和后台线程的区别、对日志、trace、系统服务这些词不会完全陌生。

更准确地说，这本书不是“零基础入门教程”，而是一本面向工程实践的中高级读物。它最适合的读者，是已经遇到过性能问题，想把零散经验系统化的人。
