# 第 10 章：内存性能

这一章讨论的不是“Android 内存管理原理”本身，而是**内存问题怎样在真实应用里变成性能问题**。

同样是内存异常，有些会表现成 OOM，有些会表现成前后台切换慢，有些会表现成频繁 GC、偶发卡顿，甚至只是“越用越沉”。如果只把内存问题理解成“会不会崩”，很多早期信号都会被忽略掉。

所以这一章更像是前面内存基础章节在性能专题里的落地版：从 App 角度看，应该怎样识别、判断和处理内存相关的性能问题。

## 本章内容

- App 内存分析
- 内存泄漏
- 内存持续增长
- 低内存对系统性能的影响
- 案例集

## 阅读建议

- 如果你遇到的是 OOM、GC 抖动、前后台恢复慢，这一章和第 4 章最好对照着读。
- 如果你主要做 App 侧问题排查，`10.1`、`10.2`、`10.3` 是入口。
