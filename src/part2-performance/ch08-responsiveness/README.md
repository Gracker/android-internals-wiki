# 第 8 章：响应速度

如果说流畅性关注的是“画面顺不顺”，那响应速度关注的就是“操作之后，系统多久给反馈”。

这两个问题在用户嘴里经常会混在一起，实际分析时却必须拆开。  
有些场景帧率很好，但点击就是慢；有些场景首帧出来得很快，但内容迟迟不可交互；还有一些问题表面像启动慢，根因却在后台恢复、数据准备或者输入到显示这条链路上。

这一章的任务，就是把响应速度从“感觉慢”拆成一条条能量化、能观察、能判断的路径。

- App 启动全流程
- 启动优化策略
- 其他响应速度场景
