## 需要保留的技术边界

| 说法 | Android 17 核查结论 |
|---|---|
| Android 17 新增 `StartupInsightsService` | `android-17.0.0_r1` 中没有该服务，也没有与之对应的 `cmd startup_insights` |
| “Startup Insights” 是可直接调用的平台 API 名称 | 平台公开类型是 `android.app.ApplicationStartInfo`；“Startup Insights”更适合作为分析主题名称 |
| `reportFullyDrawn()` 触发 start-info completion listener | listener 在启动记录达到 first-frame-drawn 状态时触发；`reportFullyDrawn()` 是另一项启动完成信号 |
| 自定义时间戳可以任意时间反复覆盖 | Android 17 实现对 key 和写入阶段有更严格限制，采集端应按 write-once、首帧前写入处理 |
| 一份 start-info 记录足以解释全部启动慢点 | 它提供启动分类与关键时间锚点；线程调度、I/O、Binder、dex / class loading 和帧显示仍需 Perfetto 等证据 |
