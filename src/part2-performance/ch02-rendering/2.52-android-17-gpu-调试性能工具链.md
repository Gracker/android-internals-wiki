## 版本边界修正

本文件的旧 metadata 写着 `Android 16 (API 35)`，这个对应关系不正确：Android 15 对应 API 35，Android 16 对应 API 36，Android 17 对应 API 37。该字段属于 OpenClaw / Hermes 状态数据，Review 中保持原字节不变；技术正文一律以 Android 17 / API 37 的 `android-17.0.0_r1` 为平台锚点，以 `android17-6.18-2026-06_r6` 为 kernel 锚点。

Android 17 AOSP 中没有 APA GPU 分析服务，也没有自动归一化不同厂商 counter 的公共映射层。AGI 是独立发布的分析工具；Profile HWUI rendering、Perfetto、AGI 和厂商 profiler 观察的是不同阶段，不能互相替代。
