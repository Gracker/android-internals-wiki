## Android 17 边界摘要

| 容易产生误解的说法 | `android-17.0.0_r1` 的核查结果 |
|---|---|
| AOSP 有 APA 系统服务，并与 AGI 在 SurfaceFlinger 内协作 | AOSP 没有该服务；AGI 是独立发布的桌面工具，包含 System Profiler 与 Frame Profiler |
| `InternedGpuCounterDescriptor` 统一不同厂商的 counter | 它提供 sequence-scoped descriptor，便于多 producer / 多 GPU 使用，不做跨厂商归一化 |
| `JankTracker` 负责计算并输出全部 jank 分类 | `FrameTimeline` 生成分类；`JankTracker` 缓存 `JankData` 并通知 listener |
| `FpsReporter` 就是 `dumpsys SurfaceFlinger --latency` | 它根据 LayerHierarchy 与 FrameTimeline 计算 task 关联 layer 的 FPS，并通知 listener |
| `sfdo` 替代 SurfaceFlinger dumpsys | `sfdo` 只调用一组有限的 `SurfaceFlingerAIDL` 内部控制接口 |
| `dumpsys gpu --gpustats` 是 GPU 利用率时间线 | 它是 GPU driver / ANGLE 等加载统计；GPU 工作、内存和硬件 counter 要分别取证 |

平台结论统一锚定 Android 17 / API 37 的 `android-17.0.0_r1`。涉及共享 buffer 与 fence 时，kernel 语义统一锚定 `android17-6.18-2026-06_r6`。
