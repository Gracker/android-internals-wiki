## 上方 outline 中的旧假设

protected outline 作为历史任务记录保留，不能当作审核后的结论：

- `Debug.getRss()` 没有“五分钟限速”；五分钟缓存属于 `ActivityManager.getProcessMemoryInfo()` 面向调用方的返回策略。
- Android 17 没有一套可概括为“PSS 三层采样”的通用 Framework 架构。
- statsd 是否采集、以什么 atom 和频率采集，需要引用具体配置，不能从 PSS API 自动推出。
- Android 手机 SoC 的 cache topology、coherency protocol 和内存控制器由硬件与 kernel topology 决定，不能用通用 NUMA 优化建议替代设备证据。
