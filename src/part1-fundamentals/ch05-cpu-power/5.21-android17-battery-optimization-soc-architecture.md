# 5.21 Android 17 SoC 厂商电池优化架构

<!-- outline-start -->
## 要点

### 🔹 SoC 功耗管理基础架构
- IPower AIDL 接口五层闭环调用链：系统服务 → PowerManagerService → Vendor HAL → Kernel Driver → Hardware
- 动态功耗调度策略：基于工作负载的 CPU/GPU/DSP 频率调整
- 电源状态管理：不同场景下的电源模式切换机制
- 温度控制策略：过热保护与性能平衡的动态调节

### 🔹 高通 RPMh/PDC 架构
- Resource Power Management Hardware (RPMh) 层级设计
- Power Domain Controller (PDC) 的电压域管理
- 电源门控技术：闲置硬件模块的智能关闭
- 性能-功耗平衡曲线：工作负载与功耗的映射关系

### 🔹 联发科 MTLP/dvfsrc 实现
- Multi-Layer Power (MTLP) 管理架构
- Dynamic Voltage and Frequency Scaling Resource (dvfsrc) 机制
- 功耗域划分：不同硬件模块的独立供电管理
- 智能调节算法：基于历史负载的预测性功耗控制

### 🔹 三星 ASV/exynos-pmu 方案
- Adaptive Supply Voltage (ASV) 电压自适应技术
- Exynos Power Management Unit (PMU) 架构
- 电源状态快速切换机制：低功耗模式转换
- 温度感知功耗调节：环境温度感知的动态调整

## 扩展

### 🔸 schedutil 与内核调度集成
- CPUFreq schedutil 算法：基于 CPU 负载的动态频率调整
- 调度器优化：不同类型工作负载的调度策略
- 大核心与小核心的协同调度：大小核负载分配
- 实时任务优先级管理：系统应用的性能保障

### 🔸 功耗优化实战
- 应用级功耗监控：BatteryManager API 使用方法
- 背景任务优化：后台应用的功耗控制策略
- 网络优化：网络操作的功耗优化技术
- 显示优化：屏幕亮度与功耗的平衡管理
