## 要点

### 🔹 SoC 级电池优化分层架构
- Framework 层的 PowerManager.setMode() 接口
- Java 层 PowerManagerService 的 DIRTY_* 位掩码管理
- Native 层 IPower AIDL 跨进程通信
- Vendor 层厂商特定的电源管理实现
- Kernel 层 cpufreq/devfreq 节点控制

### 🔸 三大厂商实现差异分析
- Qualcomm: RPMh 驱动优化策略
- MediaTek: mtlp 模块通信机制
- Samsung: ASV + TMU 双重优化

### 🔸 schedutil Governor 交互机制
- sugov_should_update_freq() 守门函数
- rate_limit_us 限流策略
- 频率决策的智能算法

- 功耗模式的场景适配

### 🔸 生产级部署方案
