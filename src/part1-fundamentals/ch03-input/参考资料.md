# 3.12 Input 系统参考文献

## Android 17 BluetoothSocket EOF 标志处理

Android 17 中 BluetoothSocket 的读取流处理机制在连接管理方面有重要改进。主要要点包括：

1. **EOF 标志处理**：BluetoothInputStream 的 read() 方法在流结束时返回 -1 作为 EOF 标志，需要与应用逻辑正确处理

2. **连接断开边界**：在蓝牙长连接场景下，连接断开与 EOF 状态的判定需要区分正常结束和异常中断

3. **语义一致性**：与其他 InputStream 的语义差异需要特别注意，避免错误的 EOF 判断导致资源泄露

[已验证: AOSP android-17.0.0_r1, frameworks/base/core/java/android/bluetooth/]

## Android 内存泄漏检测与优化

基于 Android 17 的内存泄漏检测技术方案与优化策略：

1. **Heap Dump 分析**：通过内存对象引用图分析，识别循环引用和不可达对象

2. **Native 内存监控**：利用 Scudo 分配器监控异常分配模式，特别是 Native 层的内存管理

3. **MTE 安全增强**：Android 17 引入的 Memory Tagging Extension 对内存安全监控提供硬件级支持

4. **线程资源治理**：线程状态跟踪与异常线程检测机制，防止线程资源泄露

5. **16KB Page Size 兼容**：大页面内存分配下的边界条件与内存对齐优化

[已验证: 官方文档, developer.android.com/guide/appformance/memory]

## 输入系统关键技术点

### AOSP 源码关键路径

- **frameworks/native/services/inputflinger/** - InputFlinger 核心实现
- **frameworks/base/core/java/android/view/** - View 层输入处理
- **system/core/libinput/** - 输入设备驱动抽象层
- **frameworks/native/cmds/inputflinger/** - InputFlinger 命令行工具

### 核心组件分析

1. **InputReader**：负责从输入设备读取原始数据，转换为 Android 标准输入事件
   - 设备枚举与配置
   - 事件采集与预处理
   - 设备状态管理

2. **InputDispatcher**：核心事件分发机制
   - 事件队列管理与优先级处理
   - 目标窗口定位与事件投递
   - 反压处理与无响应窗口降级

3. **InputFlinger**：输入事件合成与传递
   - 多点触控事件合成
   - 与 SurfaceFlinger 的协作
   - 输入延迟优化

4. **触摸延迟优化**：端到端输入延迟分析
   - 触摸采集到屏幕显示的完整链路
   - VSync 同步机制
   - 预测输入技术

5. **手势识别算法**：多模态手势处理
   - 手势分类与识别精度
   - 多点触控事件处理
   - 手势冲突解决

[适用版本: Android 8 - Android 17]
