# 4.37 Android 17 LMKD 用户态迁移 + PSI 协同机制

<!-- outline-start -->
## 要点

### 🔹 LMKD 内核态到用户态迁移背景
Android 17 对低内存杀手守护进程 (LMKD) 进行了重大架构重构，从内核态迁移到用户态运行，这一变更对整个 Android 内存管理系统产生了深远影响。

#### 1. 迁移动机
- **安全提升**：用户态运行降低内核攻击面，提升系统安全性
- **调试便利性**：用户态程序更容易调试和问题定位
- **功能扩展性**：用户态程序更容易添加新功能和优化
- **维护成本降低**：减少内核空间维护的复杂性

#### 2. 架构变化
- **旧架构**：LMKD 作为内核模块直接操作内核数据结构
- **新架构**：LMKD 作为用户态守护进程，通过系统调用与内核交互
- **通信机制**：使用 Netlink socket 与内核进行通信
- **权限控制**：引入更细粒度的权限管理机制

### 🔹 PSI (Pressure Stall Information) 协同机制
Android 17 集成了 Linux 内核的 PSI 机制，为 LMKD 提供了更精细的内存压力监控。

#### 1. PSI 概念解析
- **内存压力指标**：PSI 提供了 CPU、内存、I/O 的压力指标
- **延迟统计**：统计任务等待资源的延迟时间
- **压力等级**：分为 some、full、total 三个压力等级
- **时间窗口**：支持不同时间窗口的压力统计

#### 2. PSI 与 LMKD 集成
- **实时监控**：PSI 为 LMKD 提供实时内存压力数据
- **决策支持**：基于 PSI 数据做出更精确的内存决策
- **趋势分析**：通过 PSI 趋势分析预测内存压力
- **阈值配置**：根据 PSI 指标配置动态阈值

#### 3. 协同工作机制
- **数据收集**：LMKD 从 PSI 系统收集内存压力数据
- **压力评估**：评估当前内存压力等级和趋势
- **决策制定**：基于 PSI 数据制定进程终止策略
- **执行控制**：控制进程的终止和内存回收

### 🔹 新架构实现细节
Android 17 的 LMKD 新架构在多个方面进行了改进：

#### 1. 进程状态管理
- **进程优先级映射**：将 Android 进程状态映射到 LMKD 理解的优先级
- **进程组管理**：管理进程组的内存使用和优先级
- **进程生命周期**：跟踪进程的生命周期和内存使用模式
- **进程权重计算**：基于多因素计算进程内存权重

#### 2. 内存压力监控
- **动态采样**：根据系统负载动态调整采样频率
- **多维度监控**：监控 RSS、PSS、交换空间等多个维度
- **趋势预测**：预测未来的内存压力趋势
- **异常检测**：检测内存使用异常模式

#### 3. 决策算法优化
- **多因素决策**：基于多个因素做出终止决策
- **批处理机制**：批处理多个进程的终止决策
- **优先级继承**：处理进程间的优先级继承关系
- **死锁预防**：预防决策过程中的死锁情况

### 🔹 性能影响分析
LMKD 用户态迁移对系统性能的影响：

#### 1. 响应时间
- **决策延迟**：用户态决策可能增加延迟
- **通信开销**：用户态-内核态通信增加开销
- **缓存效率**：用户态程序的缓存效率差异
- **上下文切换**：增加用户态-内核态切换次数

#### 2. 内存使用
- **内存开销**：用户态程序的内存开销
- **进程数增加**：可能增加系统进程数量
- **内存碎片**：用户态程序的内存碎片影响
- **共享内存**：优化共享内存使用策略

#### 3. CPU 使用
- **计算负载**：用户态程序的 CPU 计算负载
- **调度开销**：增加进程调度的开销
- **中断处理**：处理更多的中断和事件
- **缓存影响**：对 CPU 缓存使用效率的影响
