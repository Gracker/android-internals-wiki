# 4.49 Android 17 trimMemory 回调 API 演进与 ART Heap Trim 链路

<!-- outline-start -->
## 要点

### 🔹 ComponentCallbacks2 五级 Deprecated（API 34+）
{TRIM_MEMORY_RUNNING_MODERATE/LOW/CRITICAL + MODERATE/COMPLETE 自 Android 14 起不再向应用投递}

### 🔹 仍生效的回调级别
{TRIM_MEMORY_UI_HIDDEN (20) 和 TRIM_MEMORY_BACKGROUND (40) 的语义与行为}

### 🔹 skipBgMemTrimOnFgApp 标志
{Android 17 新增 aconfig 标志，前台进程不再处理 TRIM_MEMORY_BACKGROUND}

### 🔹 ART Heap Trim 链路
{VMRuntime.trimHeap() -> Heap::Trim() -> HeapTrimTask 异步执行 RosAlloc/DlMalloc 空间归还}

### 🔹 trimMemory 对应用内存优化策略的影响
{五级 deprecated 后开发者应如何调整内存释放策略}

### 🔹 系统侧 trimMemory 触发链路
{ActivityManagerService -> AppForegroundNotifyManager -> AppThread.scheduleTrimMemory}

## 扩展

### 🔸 OEM 设备 trimMemory 行为差异
{不同厂商对 deprecated 级别的实现差异}

### 🔸 ART HeapTrim 与 ConcurrentGC 的交互
{HeapTrimTask 与 ConcurrentGCTask 的优先级和时序关系}
