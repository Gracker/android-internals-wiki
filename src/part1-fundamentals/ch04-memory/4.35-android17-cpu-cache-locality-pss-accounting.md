## 要点

### 🔹 CPU 缓存层次与 Android 性能边界
- ARM 大小核缓存拓扑：L1/L2 私有 vs L3/DSU 共享
- cache line 对齐对热点数据结构性能的影响（64B vs 128B）
- Android 17 内核 6.x 下的 per-cpu 缓存优化（slab 分配器 / buddy 系统）
- 缓存友好数据结构设计原则在 AOSP 系统服务中的实践

### 🔹 PSS 内存核算的内核实现
- `/proc/<pid>/smaps_rollup` 的内核计算路径（`mm/vmstat.c` / `fs/proc/task_mmu.c`）
- PSS = private_clean + private_dirty + shared_clean/(N) + shared_dirty/(N) 的计算逻辑
- Android 17 中 `smaps_rollup` 的性能优化：增量更新 vs 全量遍历
- 与 `procrank` / `proc/<pid>/status` VmRSS 的口径差异

### 🔹 PSS 与 LMKD 杀进程决策的耦合
- LMKD 使用 PSS 还是 RSS 进行内存压力判断（Android 17 的选择）
- `lmkd.c` 中 `proc_get_mem_size()` 的数据源解析
- PSI（Pressure Stall Information）与 PSS 联合判断机制
- 内存压力下的缓存局部性退化现象

### 🔹 DMA-BUF / GraphicBuffer 的 PSS 归属
- GPU 内存（dmabuf）在 PSS 中的核算方式变化
- Android 17 中 `dmabuf_heaps` 的 per-process 计费
- SurfaceFlinger 合成缓冲区的 PSS 分摊规则
- 多进程共享图形内存的 PSS 计算陷阱

### 🔹 ART 堆内存的 PSS 影射
- ART Java Heap（Zygote Space + App Space）在 `/proc/smaps` 中的映射
- `LargeObjectSpace` 的 mmap 匿名页与 PSS 归属
- Region-based memory management（RegionSpace）的 PSS 表现
- GC compaction 后 PSS 瞬时抖动的原因

### 🔹 缓存局部性优化对 PSS 的间接影响
- 内存紧凑布局（compaction）对 cache hit rate 的提升
- `madvise(MADV_HUGEPAGE)` 与透明大页（THP）对 PSS 的影响
- Android 17 `madvise` 新增 flag 对缓存性能的作用
- 内存碎片化 → cache miss 升高 → 性能退化的因果链

### 🔹 调试与测量工具链
- `simpleperf stat -e cache-misses,cache-references` 测量缓存命中率
- Perfetto `cpu` track + `mem` track 关联分析缓存抖动
- `/proc/<pid>/pagemap` 查看物理页分布与缓存亲和性
- `dumpsys meminfo` PSS 数据来源与内核 smaps 的对应关系
