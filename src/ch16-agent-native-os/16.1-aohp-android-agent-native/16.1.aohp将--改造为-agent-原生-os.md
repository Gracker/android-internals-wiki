# AOHP：将 Android 改造为 Agent 原生 OS

<!-- outline-start -->
## 要点

### 🔹 GPU功耗管理基础
Android 17 引入了全新的 GPU 功耗管理策略，基于 DVFS（动态电压频率调节）机制的深度优化。

### 🔹 DVFS 调优算法
新算法结合了应用负载预测和系统资源监控，实现了更智能的频率和电压调节。

### 🔹 多核心协调机制
跨 GPU 核心的功耗分配协调，根据不同应用场景动态调整核心工作状态。

### 🔹 热量控制与性能平衡
在控制 GPU 发热的同时保持最佳的性能表现，引入了热量感知的调度策略。

### 🔹 SoC 厂商定制化
支持不同 SoC 厂商的定制化 DVFS 策略，充分发挥硬件性能潜力。

## 扩展

### 🔸 游戏场景优化
针对游戏场景的特殊功耗优化策略，平衡帧率和功耗的关系。

### 🔸 AI 推理任务
AI 推理任务在 GPU 上的功耗管理，考虑模型大小和推理频率的影响。

### 🔸 后台任务处理
后台 GPU 任务的功耗管理策略，避免不必要的资源占用。
