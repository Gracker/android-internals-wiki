## 迁移提纲

- Android 17 平台源码、Perfetto v57.1 主机工具与 AI skill 是三条独立版本线。
- AI skill 是主机侧工作流包，不会在设备上部署 AI 性能诊断服务。
- State Track 是 Perfetto SDK/trace schema 能力，不等于“AI 技能生命周期”。
- 内存分析仍依赖 heap profile、heap graph、进程内存数据和可复查 SQL。
- 完整版本边界见 §13.27，内存工作流见 §13.23。

## 版本边界

| 对象 | 运行位置 | 能力边界 |
|---|---|---|
| Android 17 / API 37 / `android-17.0.0_r1` | 设备 | 决定系统能采集的数据源和 Framework 事件；不能由 API level 推出设备内置 Perfetto v57.1 |
| Perfetto v57.1 Trace Processor / SDK | 主机或显式集成该 SDK 的进程 | 提供该版本的解析、SQL 与 State Track schema；不会改写旧 trace 中不存在的数据 |
| Perfetto AI skill | Codex、Claude Code 等主机代理环境 | 提供说明、查询流程、脚本与 wrapper；不会自动发现泄漏，也不管理设备上的模型生命周期 |

State Track 可以表达任意生产者定义的离散状态，例如播放器的 `Playing`、`Buffering`、`Stopped`。若项目要记录模型加载、推理或释放，也必须由生产者显式定义 track、状态值和时间点。Perfetto 不会把某个 AI runtime 的内部状态自动转换成通用轨道。

内存分析也遵循同样的证据边界。AI skill 可以帮助运行 heap graph、heap profile 或 SQL 查询，但泄漏结论仍要核对采集范围、采样口径、对象/调用栈归属、进程版本和源码所有权。
