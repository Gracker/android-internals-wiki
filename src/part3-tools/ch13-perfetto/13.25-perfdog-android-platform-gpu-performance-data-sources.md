# 13.25 源码调研：PerfDog 的 Android 平台 GPU/性能采集底层数据源

<!-- outline-start -->
## 要点

### 🔹 PerfDog 架构与 GPU 采集原理
PerfDog 架构设计解析，Android 平台 GPU 性能数据采集的核心原理，硬件抽象层与用户空间的协作机制，不同厂商 GPU 的适配层设计。

### 🔹 SurfaceFlinger GPU 性能数据通路
SurfaceFlinger 中的 GPU 性能指标采集，帧时间统计与 GPU 负载计算，HWComposer 硬件合成与 GPU 渲染的性能数据透传，GPU 频率与功耗关联分析。

### 🔹 ANativeWindowBuffer 与 GPU 内存管理
GraphicBuffer 管理与 GPU 内存分配，BufferQueue 中的 GPU 内存池机制，内存映射与缓存策略，跨进程 GPU 共享内存的性能边界。

### 🔹 Vulkan 驱动层性能数据采集
Vulkan 驱动层的性能监控点，GPU 命令队列与提交链路追踪，渲染管线各阶段的耗时统计，GPU 计算单元与内存访问的延迟分析。

### 🔹 OpenGL ES 兼容层的数据采集机制
ANGLE 翻译层的性能数据采集，OpenGL ES 到 Vulkan 的映射开销，Shader 编译与 GPU 缓存性能监控，GPU 状态查询的优化策略。

### 🔹 游戏引擎 GPU 性能数据接口
Unity/Unreal Engine 的 GPU 性能数据获取，Engine 层与系统层的性能数据同步，帧率波动与 GPU 负载的关联分析，渲染批处理与 draw call 优化。

### 🔹 GPU 热节点的 Perfetto 集成
GPU 性能热点与 Perfetto Trace 事件的映射，GPU 计算密集型任务的识别方法，多 GPU 协同工作的性能数据采集，渲染管线阻塞的根因分析。

### 🔹 实际应用中的 GPU 性能优化案例
游戏应用 GPU 渲染优化实战，视频播放 GPU 加速性能调优，AR/VR 应用的 GPU 内存管理，GPU 频率自适应策略的效果评估。

## 扩展

### 🔸 GPU 频率调节与 DVFS 协作
GPU DVFS 控制器的内部实现，GPU 频率与系统负载的协同算法，游戏场景的 GPU 频率锁定策略，视频播放的 GPU 频率切换优化。

### 🔸 GPU 内存泄漏检测与治理
GPU 内存泄漏的识别方法，显存泄漏的自动化检测工具，GPU 资源泄漏的根因分析，GPU 内存使用的长期监控体系。

### 🔸 跨厂商 GPU 性能数据标准化
不同厂商 GPU 性能指标的统一映射，GPU 性能基准测试方法，GPU 性能测试的自动化框架，GPU 性能数据的跨平台对比分析。
