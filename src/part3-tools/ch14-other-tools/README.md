# 第 14 章：其他分析工具

前面已经花了很多篇幅讲 Perfetto，但真实工作里，性能分析不可能只靠一种工具。

有些问题更适合看 CPU 采样，有些更适合看内存快照，有些需要命令行快速取证，有些根本不是线下问题，而是线上监控和客户端增强能力的问题。  
这一章存在的意义，就是把那些在实战里经常一起出现、但又不属于 Perfetto 主线的工具收拢到同一章里。

## 本章内容

- Android Studio Profiler
- Simpleperf
- 内存分析工具
- dumpsys 系列命令
- 三方性能库
- 自动化测试工具
- ProfilingManager
- APM / 可观测性平台与 SDK 选型
- Hook 基础设施与性能工具实现原理

## 阅读建议

- 如果你已经会看 Perfetto，这一章会告诉你什么时候该换工具，而不是继续硬看 trace。
- 如果你在线上治理这条线上工作，后半章的 APM、Hook 和平台章节更重要。
