## 要点

### 🔹 Camera HAL3 架构概述

Camera HAL3 (Hardware Abstraction Layer 3) 是 Android 摄像头系统的核心抽象层，定义了硬件厂商与系统框架之间的接口协议，其中 Buffer 管理是性能关键点。

**HAL3 架构分层**：
```
应用层 (CameraX/Camera2) 
    ↓
Camera Service (CameraManager/CameraDevice)
    ↓  
CameraProvider (厂商实现)
    ↓
HAL3 Interface (camera3.h)
    ↓
Vendor Implementation (Qualcomm/MediaTek/Samsung)
    ↓
Camera Driver (Linux Kernel)
```

**核心接口定义**：
```cpp
// hardware/interfaces/camera/3.4/ICamera.hal
interface ICamera {
    // Buffer 配置相关接口
    configureStreams(StreamConfiguration streams);
    // Buffer 获取接口
    getNextStreamBuffer(StreamBuffer buffer);
    // Buffer 提交接口
    processStreamCaptureRequest(CaptureRequest request);
}
```

**Android 17 HAL3 关键改进**：
- **异步 Buffer 管理**：引入 Buffer AsyncCallback 减少轮询开销
- **内存池预分配**：启动时预分配 Buffer 池，避免运行时分配延迟
- **零拷贝优化**：通过 DMA-BUF 实现跨进程 Buffer 共享

```java
// BufferQueue 完整生命周期管理
public class CameraBufferManager {
    private BufferQueue bufferQueue;
    private GraphicBuffer.BufferAllocator allocator;
    
    public void manageBufferLifecycle() {
        // 1. Buffer 分配
        GraphicBuffer buffer = allocator.allocate(
            width, height, format, usageFlags);
        
        // 2. Buffer 入队
        bufferQueue.addBuffer(buffer);
        
        // 3. Buffer 获取 (HAL3 → Camera Service)
        bufferQueue.acquireBuffer(buffer, timeout);
        
        // 4. Buffer 使用
        cameraService.processBuffer(buffer);
        
        // 5. Buffer 释放
        bufferQueue.releaseBuffer(buffer);
        
        // 6. Buffer 回收
        allocator.recycle(buffer);
    }
}
```

**SurfaceFlinger 协同**：
- **Buffer 传输机制**：Camera HAL3 通过 BufferQueue 将处理后的 Buffer 传递给 SurfaceFlinger 进行渲染
- **同步控制**：使用 Barrier 机制确保 Buffer 在写入完成后再进行渲染
- **帧率协调**：与 SurfaceFlinger 的 VSync 机制同步，避免帧撕裂
