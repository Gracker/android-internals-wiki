# v1.0 发布标准

## 发布范围

v1.0 覆盖 5 个部分、26 章、前言和附录。发布时必须以重建后的 `src/SUMMARY.md` 为入口，但当前 `src/SUMMARY.md` 仍是短目录，不能代表最终发布范围。

发布范围的判定顺序：

1. `src/` 中具备有效 frontmatter 的正文文件。
2. `metadata/queue.json` 与 `logs/` 中仍未闭环的高优问题。
3. 重建后的 `src/SUMMARY.md` 发布目录。
4. `metadata/progress.json` 精修子集统计。

## 质量标准

| 指标 | v1.0 要求 |
|------|----------|
| 目录链接 | `src/SUMMARY.md` 中所有链接必须可解析 |
| 章节元数据 | 发布范围内正文文件通过 `scripts/check-metadata.py` |
| 流水线状态 | 发布范围内正文进入 `ready-to-publish` 或等价状态；遗留状态必须被明确豁免 |
| 队列闭环 | `metadata/queue.json` 中 P0/P1/P75+ 发布阻塞项必须完成或标为暂缓 |
| L1/L2 验证覆盖 | 核心结论具备 AOSP、官方文档、实机或可复现实验依据 |
| `[待验证]` 标记 | 不出现在关键结论、对外建议和版本边界中 |
| `[待补充]` 标记 | 仅允许出现在明确暂缓的扩展条目中 |
| 交叉引用 | 每节至少 1 个相关章节引用或清晰的上下文入口 |
| 术语一致性 | 与附录 E 和全书常用术语保持一致 |
| 构建验证 | `mdbook build` 通过，Mermaid 图正常渲染 |

## v1.0 不包含

- 英文版本（v1.0 中文内容冻结后启动翻译）
- 可运行代码示例仓库（v1.1 追加）
- 在线交互工具（v2.0 规划）

## 最小可发布版本（v0.9-beta）

如果需要先发布 beta，可按以下范围收敛：

- Part 1-3 主体章节完成发布前审校
- Part 4-5 标清“已审校章节”和“持续更新章节”
- 前言、附录、术语表和版本约定完成
- 目录链接、元数据检查、mdBook 构建全部通过
