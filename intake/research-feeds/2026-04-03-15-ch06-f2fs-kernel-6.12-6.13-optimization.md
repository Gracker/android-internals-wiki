## [研究] F2FS Linux Kernel 6.12/6.13 关键优化：Folio 转换与 GC 调优

- **映射章节**：§6.2 文件系统 + §6.4 存储相关的版本演进
- **映射锚点**：F2FS 架构、GC 机制、Checkpoint 机制、Zone UFS 支持、I/O 路径优化
- **摘要**：Linux Kernel 6.12 对 F2FS 进行了大规模 I/O 路径 Folio 转换、新增 Zoned Device GC 调优旋钮、降低 Checkpoint 触发频率、引入 Parallel DIO Reads、移除 buffer_head 使用；6.13 新增 Device Aliasing（分区空间临时借出）、多设备 DebugFS 统计、per-inode read extent count sysfs 节点。这些变更直接提升 Android 设备的 I/O 吞吐和闪存寿命。

### 关键发现
1. **Folio 转换（6.12）**：F2FS 主要 I/O 代码路径从 page 转为 folio，利用更大的内存管理单元减少碎片、提升 I/O 效率。这是 Linux 内核整体向 folio 迁移的一部分，F2FS 是最后一批完成转换的主要文件系统之一。
2. **Zoned Device GC 调优（6.12）**：新增前台/后台 GC 调优旋钮，允许更精细地控制 Zoned Device（如 UFS 4.0 的 ZBC/ZAC 模式）的垃圾回收行为，减少 GC 对前台 I/O 的性能干扰。同时引入了 F2FS_IPU_NOCACHE 选项优化 pinned file 处理。
3. **Checkpoint 频率降低（6.12）**：减少了昂贵的 checkpoint 触发频率，降低写放大和 I/O 开销，对持续写入场景（如视频录制、大量日志）有显著改善。
4. **Device Aliasing（6.13）**：允许在 F2FS 分区上创建"别名文件"，临时划分一部分空间给 VM 或容器使用，完成后删除即可回收。这在 Android 虚拟化场景（如 AVD、容器化应用）中提供灵活的存储管理能力。
5. **Parallel DIO Reads（6.12）**：支持并行 Direct I/O 读取，提升大文件读取吞吐量，对媒体播放、数据库查询等场景有利。
6. **Zone UFS 写入优先级（6.12）**：新增基于 Zone UFS 的写入优先级选项，优化顺序写入路径。

Kernel 6.13 adds device aliasing for temporary partition space reclamation, multi-device DebugFS statistics, and a sysfs node to limit per-inode read extent counts.
