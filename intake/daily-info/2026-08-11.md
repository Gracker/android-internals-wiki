- 摘要：Perfetto UI 的 GPU 频率轨道依赖 Linux 标准 tracepoint `power/gpu_frequency`，而基于 Linux 4.9 的高通 BSP（如 sdm710）在 `include/trace/events/power.h` 中没有定义该事件，KGSL 驱动只上报自有的 `trace_kgsl_pwrlevel`，导致抓到的 trace 里既无频率折线也查不到对应 counter 数据。作者的修法是先在标准电源头文件中补齐 `gpu_frequency` 宏定义（参数为频率与 gpu_id），再在 `drivers/gpu/msm/kgsl_pwrctrl.c` 的频率切换函数中补一次事件触发，重新编译 boot.img 刷机后 Perfetto UI 与 SQL 查询均可取到 GPU 频率数据。
