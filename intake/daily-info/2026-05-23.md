## [每日论文精读] AppFlow: GB级大型App冷启动内存调度优化
- **来源**：每日论文精读（Android）
- **时间**：2026-05-23
- **链接**：https://arxiv.org/abs/2603.17259
- **摘要**：GB级大型应用（端侧LLM、大型多媒体编辑器、3D游戏）在移动端冷启动延迟极高，用户感知1秒是可用性悬崖，但86.6%的GB级冷启动超过1秒。现有优化（预加载、内存回收、进程杀灭）各自为政、相互冲突——预加载消耗内存但被回收机制撤销，回收释放内存但牺牲后台保活，导致反复冷启动。AppFlow提出系统级联合调度框架，包含Selective File Preloader（根据文件热度分级预加载，小文件用小I/O块预加载减少stall，大文件用大I/O块流式传输最大化吞吐）、Adaptive Memory Reclaimer（感知预加载的页保护，回收时跳过预加载文件避免重复读取）、Context-Aware App Killer（利用应用内存膨胀-重置特性，优先杀灭内存膨胀且长期运行的应用）。在Pixel 8（8GB）高负载下将PUBG冷启动从1689ms降至972ms（↓42.8%），Qwen2.5从2027ms降至717ms（↓64.6%），100天测试维持95%启动在1秒以内，并发保活能力提升1.85×。论文获得MobiCom 2026接收，是Android冷启动优化领域的重要工作。
- **推荐映射章节**：ch02-android-framework（Framework层内存管理）、ch05-rendering（启动性能与UI渲染）
- **内容类型**：论文
- **相关标签**：#启动 #内存 #功耗 #Perfetto #AndroidFramework
